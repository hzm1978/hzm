## 版本内容

正文八节，补充材料七节。主线集中于局域量子场测量支持资源主张所需的条件。补充测量反作用、双可分反例及局域信道不变性的论证，区分模型预测、实际认证和来源归因。点极限结果限定为二阶系数，并明确适用范围。

102 条参考文献均在正文引用，96 条带核对后的 DOI，5 条明确引用预印本版本。中英文文档检查、引用编号检查和指定算例复核已通过；具体核验范围及局限在完整包中说明。

## 使用说明

优先下载完整包查看材料。英文包用于整理投稿文件；中英文补充材料各自与相应正文配套。编译和数值复核说明位于压缩包内的 README 与 reproducibility 目录。

FoP 鼓励综述作者先向主编提供提案。提案、邮件正文及投稿信均为草稿，目前尚未发送或向期刊投稿。本分支随后按作者要求上传；压缩包内关于发布状态的文字记录的是本次 GitHub 上传之前的修订交付状态。

`SHA256SUMS` 可用于校验下载文件：

```bash
sha256sum -c SHA256SUMS
```
