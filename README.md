## 本次修复

- 修复 pandas 写时复制/只读数组导致数据更新失败的问题。
- 时间轴加减按一个实际交易日移动；周线/月线使用真实日线补充缺失的分钟历史，按选定日累计显示，缺少数据时明确标识。
- 保留 10 月 31 日周六不生成独立日 K 的修复，夜盘分钟归入后续交易日。
- 根据上传的《趋势交易法》相关章节，统一显示波浪线、趋势线、正确构造的拐点线、历史回调比例、九类关键位置 K 线反转，以及简单/ABC/平台型和三角/扩张三角/钻石/旗形/楔形调整。
- 调整形态区分候选、顺向突破和反向破位，回放分析不读取未来 K 线的最终 OHLC。
