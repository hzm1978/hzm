# 期货复盘训练系统 v8：父、子、孙结构与回调尺

[直接下载完整源码包 futures_replay_fixed_v8.zip](https://github.com/hzm1978/hzm/raw/refs/heads/fix/futures-replay-trading-days/futures_replay_fixed_v8.zip)

依据用户指定的最新版 **3.pdf**（《趋势交易法》第三版，731页）修改所有品种共用的趋势指标。按父浪段分别识别下一级子结构，再保留子浪内部的孙结构；同一时间内父、子、孙可以共存。沪银、沪锡仅为例子，没有按品种或截图硬编码数浪。

## 本版变化

- 品种列表过滤“商品说明”“品种清单”两个资料目录，主连列表和品种下拉框都不再将它们当作交易品种。

- 较早的长主浪内保留波浪线、Q区间根数、回调百分比、调整形态、子A/孙A、趋势/拐点线及符合位置条件的反转K线，不再只留下右端最近几组调整。
- 小反弹即使内部有完整五子浪，也先判断它在父趋势中的归属；缺少同级反转证据时，继续作为父趋势的调整内部结构。
- 下降趋势末段向上调整时，黄金分割取反弹之前的完整下降主浪，从底向顶量回；上涨趋势对称。水平线从前段起点处画出，比例和价格在线上。
- 正在进行的第5子浪候选若已被收盘破坏则撤销；三角/复杂调整重新确定c/e后，按实际结束点重新核对。区间不能合法合并时显示“延续结构·待重分级”，不强凑第9浪。

## 最后一段怎样显示

| 当前状态 | 图中价位标注 |
|---|---|
| 顺工作级别的趋势方向推进 | 最近三个尚未触及的书中候选止盈参考，数字在线上；不画黄金分割 |
| 反向调整，例如下跌趋势中向上反弹 | 前一完整下跌浪的0%、23.6%、38.2%、50%、61.8%、78.6%、100%回调尺；不画可能止盈位 |
| 横盘调整 | 前一完整浪段的黄金分割，不画趋势止盈位 |
| 已完成的历史主浪 | 末端只标一个实际到达价；完整分级及理论目标留在明细 |

例如3919.71→3174.45的下降之后向上反弹，50%为3547.08，61.8%为3635.02。书中40%/62%/78.6%的结构位置参考与这把标准回调尺分别记录。当前工作方向、依据的Q、父段归属、候选及确认时刻可在 **指标明细** 和JSON中核对。

## 安装

退出旧程序并备份。解压后用整个 `futures_replay` 文件夹覆盖旧同名文件夹，保留行情与交易记录；同时复制 `requirements.txt`、`run.py` 和两个批处理。先运行 **安装或更新依赖.bat**，再运行 **启动程序.bat**。窗口标题应显示 **v8.0.0**。

源码包需要Python，不是独立exe。两个批处理优先使用包内或上一级已有 `.venv`，否则使用系统Python。

```text
python -m pip install -r requirements.txt
python run.py
```

勾选 **趋势交易**，点击 **指标明细**。旧“波浪”工具不必同时勾选。
