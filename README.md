# 期货复盘训练系统 v8.3：实时窗口自动更新、品种联动与成交量开关

[直接下载完整源码包 futures_replay_fixed_v8_3.zip](https://github.com/hzm1978/hzm/raw/refs/heads/fix/futures-replay-trading-days/futures_replay_fixed_v8_3.zip)

依据用户指定的最新版 **3.pdf**（《趋势交易法》第三版，731页）修改所有品种共用的趋势指标。按父浪段分别识别下一级子结构，再保留子浪内部的孙结构；同一时间内父、子、孙可以共存。沪银、沪锡仅为例子，没有按品种或截图硬编码数浪。

## 本版变化

- 打开 **实时跟随** 自动连接并更新当前品种；已记住账号直接连接，首次未保存时提示登录一次。先显示本地最新K线，取消登录或连接失败也保留已有图形。
- 顶部品种下拉框、主连列表点击都会同步实时窗口。切换复用同一后台进程，不反复登录；当前模式的分钟/日线保存随新品种切换，全部模式继续采集原全部品种。
- 实时窗口新增 **成交量** 勾选框，取消即可隐藏副图；切换品种、关闭再开和重启程序都记住这个选择。它不影响行情采集或原复盘窗口的成交量设置。
- 切换品种保留实时窗口自己选择的周期与指标设置，旧品种的迟到数据不能覆盖新图。原盘各品种自己的复盘时刻和模拟账户不被实时更新推到最新。

以下v8.2的本地优先显示继续保留：

- 打开 **实时跟随** 就异步读取本地原行情和已保存实时增量的最新K线，并跳到最右端；无需先手动启动后台，休市、断网和取消登录后仍可显示已有数据。
- 当前画面会注明“本地最新K线”和实际时间。后台收到行情后接续更新；重启同一订阅、重开窗口或收到空数据不会清空已有K线。实时返回比已显示数据更旧时不倒退，短窗口按时间更新并保留本地历史。没有本地数据时明确提示，不伪造新K。
- 本地读取在独立线程、使用独立缓存；日线先读现成日K，切换周期/合约时丢弃过期结果，迟到的本地读取不覆盖新实时图。原复盘和账户保持原位。
- 实时窗口标题明确显示 **v8.3.0**，顶部品种文字的提示可查看实际运行模块路径，方便确认更新生效。

以下v8/v8.1修复继续保留：

- 修复刚启动后台就打开实时窗口的协议顺序错误：先发送登录/配置，再发送最后选择的看图请求。启动时切换周期或关闭窗口也按最终选择处理。
- 实时窗口同步连接及服务端错误，等待所选周期时显示进度；后台停止后保留窗口及停止原因。分钟已就绪时不再等待另一份日历订阅才显示。
- 实际联机验证SM主连日线显示2000根，最新日线2026-11-03，报价14:59:59.617001（北京时间），后台保存成功。

- 品种列表过滤“商品说明”“品种清单”两个资料目录，主连列表和品种下拉框都不再将它们当作交易品种。

- 较早的长主浪内保留波浪线、Q区间根数、回调百分比、调整形态、子A/孙A、趋势/拐点线及符合位置条件的反转K线，不再只留下右端最近几组调整。
- 小反弹即使内部有完整五子浪，也先判断它在父趋势中的归属；缺少同级反转证据时，继续作为父趋势的调整内部结构。
- 下降趋势末段向上调整时，黄金分割取反弹之前的完整下降主浪，从底向顶量回；上涨趋势对称。水平线从前段起点处画出，比例和价格在线上。
- 正在进行的第5子浪候选若已被收盘破坏则撤销；三角/复杂调整重新确定c/e后，按实际结束点重新核对。区间不能合法合并时显示“延续结构·待重分级”，不强凑第9浪。

## 最后一段怎样显示

| 当前状态 | 图中价位标注 |
|---|---|
| 顺工作级别的趋势方向推进 | 最近三个尚未触及的书中候选止盈参考，数字在线上；不画黄金分割 |
| 反向调整，例如下跌趋势中向上反弹 | 前一完整下跌浪的0%、23.6%、38.2%、50%、61.8%、78.6%、100%回调尺；不画可能止盈位 |
| 横盘调整 | 前一完整浪段的黄金分割，不画趋势止盈位 |
| 已完成的历史主浪 | 末端只标一个实际到达价；完整分级及理论目标留在明细 |

例如3919.71→3174.45的下降之后向上反弹，50%为3547.08，61.8%为3635.02。书中40%/62%/78.6%的结构位置参考与这把标准回调尺分别记录。当前工作方向、依据的Q、父段归属、候选及确认时刻可在 **指标明细** 和JSON中核对。

## 自动跟随与免费实时更新

选好品种后勾选 **实时跟随**，窗口先读本地最新K线并自动发起连接。已加密记住账号时无需再输入；首次提示登录，取消后继续显示本地数据。选择不同品种时窗口自动切换，窗口自己的周期与成交量开关保留。

“免费实时”及原单品种/全部更新入口继续保留。正在运行“实时更新全部”时，打开或切换实时窗口复用该进程；当前模式则把采集与保存切到新选择的品种。原始行情会重新解析实际主力合约，不因曾查看过的旧合约而停在旧主力。

采集在独立低优先级进程中进行；本地预览用独立线程。关闭实时窗口停止图形推送，后台继续当前范围；手动停止或退出程序才停止采集。状态保留真实行情/保存时间，不伪造休市新K线。Windows记住登录使用当前用户DPAPI加密，公开源码和ZIP不含真实账号密码。

免费范围是每周期最近最多10000根，并非固定一年；已有更早本地历史保留。v7和v8.1的真实联机证据见验证记录，本次用模拟SDK驱动生产采集器与真实Qt检验联动，未重复登录真实账号。

## 安装

退出旧程序并备份。解压后用整个 `futures_replay` 文件夹覆盖旧同名文件夹，保留行情与交易记录；同时复制 `requirements.txt`、`run.py` 和两个批处理。先运行 **安装或更新依赖.bat**，再运行 **启动程序.bat**。主窗口和实时窗口标题都应显示 **v8.3.0**。如果仍见“等待当前合约的实时行情…”且标题无版本，运行的实时窗口仍来自旧文件；请关闭所有旧窗口，从覆盖目录内的批处理启动。

源码包需要Python，不是独立exe。两个批处理优先使用包内或上一级已有 `.venv`，否则使用系统Python。

```text
python -m pip install -r requirements.txt
python run.py
```

勾选 **趋势交易**，点击 **指标明细**。旧“波浪”工具不必同时勾选。
