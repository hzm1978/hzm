## 最后一段怎样显示

| 当前状态 | 图中价位标注 |
|---|---|
| 顺所属级别的趋势方向推进 | 最近三个尚可到达的书中止盈参考，画横线段，比例与价格在线上；不画黄金分割 |
| 反向调整，例如下跌趋势中向上反弹 | 取前一完整下跌浪，从底向顶画黄金分割；不画可能止盈位 |
| 横盘调整 | 最后段只画前一完整浪段的黄金分割，不画趋势止盈位 |
| 已完成的历史主浪 | 末端只标一个实际到达价，不堆叠多个假设止盈位 |

上涨趋势按相反方向对称处理。主浪推进继续区分候选；1.208/1.618/2倍H1和强势扩展、全趋势参考按所属级别计算，完整价格与命中时刻保留在明细。最近两个转折增加形态观察；未达到标准或位置条件的形态标“候选/观察”，不提升为正式信号。子浪、区间根数、回调%、调整类型、A点和趋势/拐点线继续保留。

## 安装

退出旧程序并备份。解压后用整个 `futures_replay` 文件夹覆盖旧同名文件夹，保留行情与交易记录；同时复制 `requirements.txt`、`run.py` 和两个批处理。先运行 **安装或更新依赖.bat**，再运行 **启动程序.bat**。窗口标题应显示 **v7.0.0**。

源码包需要Python，不是独立exe。两个批处理优先使用包内或上一级已有 `.venv`，否则使用系统Python。命令行：

```text
python -m pip install -r requirements.txt
python run.py
```

勾选 **趋势交易**，点击 **指标明细** 查看依据、候选状态、确认时刻及JSON导出。旧“波浪”工具不必同时勾选。
