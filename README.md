# 期货复盘训练系统 v4：趋势交易法第三版重写

[直接下载完整修复包 futures_replay_fixed_v4.zip](futures_replay_fixed_v4.zip?raw=true)

依据最新版 **3.pdf**（《趋势交易法》第三版，共731页）重写趋势指标核心，通读全书文字并核对关键规则图示。包括区间跨度与级别、波浪线、趋势/拐点线、主A/导A、标准K与关键位置反转、第三版四类调整浪、回调%、延时突破及PSTD参考。

新增 **指标明细**：逐层开关、参数保存、区间根数与dif/δ、A点结构与确认时间、标准K取样、规则书页及JSON导出。

## 使用

退出旧程序并备份，解压后用整个 `futures_replay` 文件夹覆盖原同名文件夹，所有新模块都要复制。保留原行情与交易记录。重启后勾选 **趋势交易**，点击 **指标明细**。独立旧“波浪”工具不必同时勾选。

源码也直接保存在本仓库，可使用Python启动：

```text
python -m pip install -r requirements.txt
python run.py
```

这是完整Python源码包，不是独立exe安装程序。已有运行入口仍可使用。
