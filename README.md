## 安装

完全退出旧程序，先备份。解压后用整个 `futures_replay` 文件夹覆盖原同名文件夹，保留行情与交易记录；同时复制本包的 `requirements.txt`、`run.py` 和两个启动/安装批处理。先双击 **安装或更新依赖.bat**，完成后双击 **启动程序.bat**。窗口标题应显示 **v6.0.0**。

两个批处理优先使用包内或上一级目录已有的 `.venv`，否则使用系统Python。源码包需要Python环境，不是独立exe安装包。命令行也可运行：

```text
python -m pip install -r requirements.txt
python run.py
```

勾选图表的 **趋势交易**，点击 **指标明细** 查看分层开关、依据、候选状态、确认时刻及JSON导出。新增图层默认开启；旧“波浪”工具不必同时开启。
