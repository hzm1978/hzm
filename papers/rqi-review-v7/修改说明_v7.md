# v7 实质修改说明

## 1. 收紧文章定位

题目、摘要、引言和结论统一为“局域测量—资源提取—可靠认证”。仍按批判性叙述综述处理，不改包装成原创研究或系统综述。

新增与既有综述的定位比较表，说明本文在子系统、耦合与支撑匹配、测量输出和资源认证上提供什么综合。
这不是“前人从未讨论过这些问题”的优先权主张。

从正文及补充材料移除与主线联系较弱的卫星网络、独立量子时钟、引力态传输与相关长篇上下文。
通信与计量保留为两个简洁的效用检验，不再各自发展成独立综述。
合并反复出现的“某个见证并不自动意味着另一项结论”，把必要限定组织为比较表和具体例子。

## 2. 提升可检查的评述

把四比特双可分态却有原始残余指标 π4=1 的反例提升至正文，明确定义 Bell 态及 N=2𝒩 的负性归一化。
把簇态冻结解释为局域 CPTP 信道下的结构性不变性，不归因于 Unruh 特有保护。
一阶 W/Dicke 模型新增显式状态公式和复算代码；不把归一化后的诊断模型解释为精确 CPTP 演化。
明确区分截断模型不受控与“精确动力学不存在复苏”这两个不同判断。

## 3. 技术修正

- 原 S12.3、现 S10.3：修正跨探测器 Wightman 函数。反频率热项使用共轭径向谱因子，而不是两项共用同一复因子。
  正文给出简式，补充材料说明产生／湮灭算符推导、局域极限和对易子占据数抵消。
- 正文电磁角核：明确垂直方向为 `(4π/3)(2j0−j2)`，平行方向为 `(8π/3)(j0+j2)`，均在零分离时等于 `8π/3`。
  补上原概述中不完整的方向对应和比例因子。
- S7：近似互信息代入式不再标为已认证的“上界”。改为 ansatz plug-in / 近似代入值；正文与表格统一。
  未证明 ansatz 在精确互信息之上，不能据此获得严格参数区间。
- S10.2：Hartle–Hawking 详细平衡比改称热一致性检查；该比值不能独立验证绝对径向归一化。
- 模流详细公式从正文集中移入 S7，避免与主文的数据处理证明混淆。
