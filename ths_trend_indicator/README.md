# 趋势交易 · 同花顺期货通电脑版 1.1.4

基于用户从4.39.1.2导出的完整函数库制作的主图公式，使用期货通自身行情，适用于各品种与周期。源码、生成器、原样函数库、检查工具和合成示例均在包内。运行指标不需要Python或账号。

本版重点是**P连续标出完整段，价格尺与P共用起止点**。**先加载新版EWT01、EWT02即可看完整P和转折形态**；要较早历史细节/画线工具再追加EWT03，要当前回调S再追加EWT04。不要继续叠加旧版四层。

## 本版显示

- P从完整前浪实际起点画到实际末端，不再只取最近八个细转折而漏掉中间。P的轮廓、Q区间根数、回调百分比、调整候选和已观察端价均在EWT02。
- 从起点向后寻找实际Q。第一Q要求收盘越过原高/低，以后允许影线越过；起始根不计。调整中的第一个局部高/低不会自动成为整段调整终点。匹配的abc取c，三角/abcde取e，允许e不是最极端价格。
- P上的浅蓝数字按所选推进/调整腿顺序编号。**腿数本身不证明书中5浪或7浪已经完成**；主级及历史子结构的书本计数另检查Q耦合、连续同级与1.618高度合并。
- P Q是区间跨度；RET%是调整幅度除以前一推进腿幅度，可超过100%；P AD编号见中文图例。P END旁的价格是已经出现的端点，P TIP?表示还在变化。P LEN为整段起止的K线跨度。
- 已完成P内部仍保留转折K线OBS RV观察，不再因为当前正在回调而只留下最近两个转折。形态标在完成根；KEY另要求标准大小与关键位置。
- 紫红色当前调整识别保留；历史P内能匹配起止归属的复杂调整也画紫红折线，未知形态保留AD0。
- 没有同级H1时仍显示已经观察到的P轮廓，H1 NA只约束候选止盈位。主级新极值出现后的小级回调成立，不再等BN根才允许画回调尺。

## 黄金分割与止盈位

| 行情与末段 | 价格尺 |
|---|---|
| 趋势，末段主浪 | 同组H1最近三个未触及候选止盈位；无黄金分割 |
| 趋势，末段回调 | 回调前一整段P的黄金分割；无止盈位 |
| 震荡 | 前一完整波段黄金分割；无趋势止盈位 |
| H1依据不足 | 保留轮廓与实际端点，不编造目标 |

0%位于前浪末端，100%位于前浪起点。因此**前浪下降、当前反弹时，下方0%、上方100%**；前浪上涨、当前回落时相反。不是把所有行情的标尺固定成同一个方向。

已成立完整P的起点优先于合并父浪的更早起点；末端若继续创新极值则保留实际延伸。近乎完整反向走回同一区间后，采用较新的已成立P，避免沿用旧方向的倒置标尺。人工MANF锚点优先。XRET按实际取尺段计算，XRDIR为当前实际价格尺方向。

自动趋势/震荡以工作高低点和重叠程度判断；SIDE的25%漂移阈值、反向范围78.6%及邻近23.6%判据属于程序选择，不冒充原书唯一市场分类。可用DIR/KIND人工核定；其余边界见[实现范围](docs/实现范围.md)。

## 安装

1. 解压并保留整个包备份，从主图移除旧指标。
2. 在指标管理中打开或新建EWT01，类型选**主图叠加**，保存至**本地**。说明及外部参数表留空，全文替换为`formulas/install/EWT01.txt`，测试后保存。
3. 更新并加载EWT02。EWT03为较早历史细节/画线工具，EWT04为当前回调S，按需追加；只在P末端之后已有合格结构时出现S，简单反弹不会硬凑浪号。
4. 不要拼接文件，不要粘贴超长的`formulas/EWTN_ASCII.txt`，它仅用于开发复查。

| 安装文件 | 分工 |
|---|---|
| EWT01 | 主级浪形、当前调整、P范围内转折K线观察 |
| EWT02 | 完整P轮廓、Q长度、回调%、调整候选、主浪端价、唯一价格尺 |
| EWT03 | 较早两段完整主浪内部信息、趋势线与拐点工具 |
| EWT04（可选） | 当前回调S，不代替完整P |

每份ASCII文件≤79500字节，无BOM、注释或隐藏字符。2026-11-05实测内容服务80000字符通过、80001拒绝；这是服务观察值，非官方永久编译器限制。所有新层参数须同步；不另建同名外部参数。安装模式固定SHOWBOOK=1、DETAIL=0。

## 参数

| 参数 | 默认 | 用途 |
|---|---:|---|
| GN / PN / BN | 1 / 2 / 7 | 细Q种子、细转折确认、父级确认；1≤GN<PN<BN |
| DIR | 0 | 0自动，1指定上涨，`0-1`指定下跌 |
| KIND | 0 | 0自动，1主浪，2回调，3震荡 |
| BOOKBARS / SPAN | 600 / 90 | 结构搜索根数 / 水平价位线最大长度 |
| SHOWSUB | 1 | P和历史子结构开关 |
| SHOWGRAND | 1 | 保留兼容参数名，本版控制可选EWT04的回调S |
| SHOWQ / SHOWK / SHOWF / SHOWT / SHOWC | 1 | Q / K线形态 / 黄金分割 / 止盈位 / 调整与画线工具 |
| MANF | 0 | 1使用人工前浪锚点 |
| MFROM / MTO / MFAGE | 0 / 0 / 90 | 前浪起价 / 末价 / 起点距最新根数 |
| MH1 | 0 | 正数使用人工同级浪1高度，0自动 |
| MBASE / MORG / MAGE | 0 / 0 / 0 | 前调整末价 / 浪1起价 / 调整末点距今根数 |
| STRONG | 0 | 人工启用额外强势候选 |

下降参数写`DIR:=0-1;`，不要把整个右侧包成`(0-1)`，现行原生内核对后者会算空值。人工价格允许0/负值；MFAGE/MAGE应在加载历史内，新增K线后相对距离需维护。人工MTO找不到对应已观察极值时仍画用户指定标尺，但不伪造P的实际结束日期。

## 范围与确认

P每次最多详细展开5组Q。超过5组或BOOKBARS时标P DETAIL LIMIT，剩余轮廓继续按已确认细转折连接，不假装细节已全部分级。主级/较早子结构各检查最多8个交替点。未实现无限递归、全部失败Q重分级、所有复杂调整组合及Tp/Ta时间预测。

波浪解释采用当前查看末端冻结、回标和位移，会随新K线变化；画回历史极值不等于当时已知信号。未收盘K为预览。P END是已观察价格，未来主浪只能给候选位置。本指标不发送交易指令。
