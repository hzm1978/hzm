# 趋势交易 · 同花顺期货通电脑版 1.1.0

依据用户从 **4.39.1.2** 导出的 `all_func.json` 制作的原生主图公式。包含波浪连线、Q区间跨度、子浪回调百分比、调整形态、分界A、转折K线观察，以及互斥的候选止盈线/黄金分割线。使用期货通自身行情，适用于不同品种与周期。

本次接入书本结构模块，修正此前漏掉长下降内部五子浪的问题。连续历史连线使用 `POLYLINE`；独立结构段、Q跨度及价位线使用 `DRAWLINE3` 的端点位移。实际调用均与所附函数库核对。

**本地解析、数值回归和绘图几何检查结果见 `docs/本地检查结果.json`。当前环境没有Windows期货通客户端，完整公式的原生编译、显示及速度仍待实测。** 合成预览与客户端实测分别记录。

## 安装

1. 解压整个包，打开 `formulas/趋势交易_PC主图_UTF8.txt`，复制全文。
2. 期货通电脑版 → 公式管理/自编指标 → 新建技术指标 → **主图叠加**。
3. 清空旧公式，粘贴完整新版，点击测试/编译，成功后保存并选用。顶部参数已在公式内赋值，无需另建同名参数。
4. 若文字乱码，使用对应GB18030文件，两种编码内容相同。建议先加载300～3000根K线，以默认参数查看日线，再按波动调整取点尺度。

安装指标只需上述TXT。Python文件提供完整生成、复查及结构明细导出源码，指标运行无需Python、天勤登录或交易账号。

两套价格尺互斥。历史工作转折旁保留一项实际到达价格。标题“工作方向”：1上升、-1下降、0待定；“末段状态”：1顺势、2调整、3横盘；“价格尺方向”记录所选价格依据的方向。

趋势线连接工作起点与终端极值之前的合适调整点，检查锚间穿价；拐点线另用对边外延线斜率平移并检查包络。直接收破观察检查标准大小、距离、深度和结构，否则使用突破根及后两根的延时水平；后续创新极值会过滤延时解释。

## 搜索范围

搜索采用最近BOOKBARS根，每组最多8个交替端点。主级下面展开当前段和前一段的子结构，再展开最近有效子结构末段的孙结构。Q负责检验计数；GN/PN/BN提供取点，不直接等同于原书级别。

调整识别覆盖简单、标准/收缩/强势abc、收缩/扩张三角、趋势/横向/不规则abcde，以及有内部收盘Q和路径包络证据的复杂1-3-1候选。更长复杂组合、两个三角的钻石/X调整组合、失败Q重分级、无限历史递归和Tp/Ta时间目标仍需人工核对。五/七浪的钻石/X与同名调整组合是不同结构。

原书允许多种合规数法，图上采用“结构解释/候选”。同级H1证据不足时显示依据不足；本组目标全被触及时保留本组依据并显示状态。详细边界见 [实现范围](docs/实现范围.md)。

## 参数

修改公式最上方的数值，再测试保存。

| 参数 | 默认 | 用途 |
|---|---:|---|
| GN/PN/BN | 1/2/7 | 孙/子/工作取点右侧确认根数，整数且1≤GN<PN<BN |
| DIR | 0 | 0自动，1指定上涨，`(0-1)`指定下跌 |
| KIND | 0 | 0自动，1顺势，2调整，3横盘 |
| BOOKBARS | 600 | 当前结构搜索的实际K线根数 |
| SPAN | 90 | 价格尺及参考线最多向左显示的根数 |
| SHOWBOOK | 1 | 书本图层；0保留基础观察显示 |
| SHOWSUB/SHOWGRAND | 1/1 | 子/孙结构显示开关 |
| SHOWQ/SHOWK/SHOWF/SHOWT/SHOWC | 1 | Q/反转/回调尺/目标/结构工具开关，0关闭 |
| DETAIL | 0 | 1增加历史基础Q/端价及全部关键形态，0合并紧邻的重复反转提示 |
| MANF | 0 | 1使用人工核定前完整浪的锚点 |
| MFROM/MTO/MFAGE | 0/0/90 | 人工前浪起价/止价/起点距最新K的根数 |
| MH1 | 0 | 正数使用人工核定同级浪1高度，0自动 |
| MBASE/MORG/MAGE | 0/0/0 | 人工H1的前调整末价、浪1起价、调整末点距今根数 |
| STRONG | 0 | 人工开启强势条件后增加2.382/2.618/3倍候选 |

人工价格允许0与负数。MFAGE/MAGE须在加载历史内，MAGE≥1；它们是相对距离，新增K后需维护。自动模式随当前前缀更新。

例如前下降浪3919.71→3174.45后正在反弹，可指定 `DIR:=(0-1); KIND:=2; MANF:=1; MFROM:=3919.71; MTO:=3174.45;`，再设置实际MFAGE。50%为3547.08，61.8%为3635.02，回调尺保留前浪完整起止位置。

## 确认时间

标准K、方向观察、原始Q、形态与关键位置在END_ANALYSIS前计算，经过前缀因果性检查。其后的当前结构图层使用末值冻结、回标与位移绘图，后续K线会使解释重选；浪号画回实际极值的位置不能当作当时已知的交易信号。

末根未收盘时的收破、形态和目标触及属盘中预览。指标不发交易指令。A确认、A失守与工作方向观察各有独立状态，局部A失守不会无条件改为父趋势反转。

## 源码与复查

- generate/compatibility：生成、条件数值转换、REF边界和安全短变量名。
- book_layers/corrections/lines/prices、candle_patterns：结构、调整/A、画线工具、价格尺与K线形态。
- reference/all_func.json、catalog：用户函数库原样文件及定义读取；其中示例只作资料，未执行代码或交易示例。
- check_formula/catalog_math/plot_audit：本地解析、数值模型、绘图几何复查，独立于官方编译器。
- tests：独立排序、实际Q事件扫描、四类七浪耦合、合并、归属、三角e、A状态及价格尺回归。
- inspect_structure：输出结构、Q起止/长度、归属、回调、A确认位置及全部H1目标状态。
- 变量映射.json、结构字段.json：模块字段与导出短变量对照。
- docs：函数依据、检查记录、六组合成预览和对应JSON明细。

Python 3.11+，在本目录运行：

```text
python -m pip install "numpy>=1.26"
python verify.py
python inspect_structure.py --scenario fall_rebound --output structure.json
python inspect_structure.py --csv candles.csv --output own_structure.json
python -m pip install matplotlib
python inspect_structure.py --scenario seven_expanding --output seven.json --preview seven.png
```

CSV按时间升序，列名O/H/L/C或open/high/low/close；bar_index从0起指向实际行。检查工具读取给定数据，不连接期货通或账号。
