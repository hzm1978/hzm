# 趋势交易 · 同花顺期货通电脑版结构观察版 1.0.6

本版修正1.0.5“文字显示但波浪和价位线消失”的实际问题。用户从4.39.1.2函数库提供的原文已确认：**DRAWLINE在同一根K线上画线；POLYLINE才连接不同K线的取值。** 旧版只核对颜色参数和数学值，漏掉了函数绘图语义。现在主图17处跨K线绘图均改用三参数POLYLINE，不再调用DRAWLINE。说明摘录见 [客户端函数说明](diagnostics/client_function_reference.txt)。

同时修正计算和显示：

- 自动方向增加先前已知工作高低点的收盘突破处理；方向证据只在变化时更新，破位后不被未变的旧双点条件在下一根覆盖。它仍是方向观察，不替代原书正式分界A确认。
- 逆势回调尺锁定本次工作方向切换时的起端，保留整个工作段的极值；内部小回调不再把尺缩成最近一条小腿。横盘用最后完整工作腿，即使工作方向待定也可画尺。
- 顺势候选目标与逆势/横盘回调尺互斥；自动H1还要求其锚点属于当前工作段，避免套用旧段依据。
- 趋势参考与对边平移参考分别计算斜率，参考线仍未完成正式包络认证。
- 默认只显示最近的端价、细Q数字和最新工作Q关系，隐藏反复出现的“细Q收破”等文字。DETAIL=1可查看更多历史；回调与目标价格向左移，避免挤出右边界。

**本地70项检查及导出AST几何检查通过，1.0.6完整主图尚未在Windows客户端实测。** 包内预览使用合成OHLC，按导出公式和客户端绘图定义生成，不是实际行情或期货通截图。旧版1.0.5已由用户截图证明能显示数值但绘图不正确，不能继续当作可用版。验证范围见 [验证记录](docs/验证记录.md)。

本公式不需要天勤、Python或账号登录；生成器和检查源码用于复查。它仍是双尺度结构观察版：父子孙完整五/七浪数法、全部调整形态和正式分界点规则尚未完整移植，不把局部转折标成已确认书本结构。见 [实现范围](docs/实现范围.md)。

顶部设置保持原名，内部短名对照在变量映射.json。标准K仍为TTSTD，避开SK等交易保留名。**升级必须清空旧公式，粘贴新版全文**，不能只改几行或与旧代码拼接。

## 安装

1. 解压整个压缩包。
2. 打开`formulas/趋势交易_PC主图_UTF8.txt`复制全文。若文字乱码，使用对应的GB18030文件，两种编码内容相同。
3. 在期货通电脑版找到**公式管理/自编指标**，新建**技术指标**，选择**主图叠加**，名称可填“趋势交易观察”。不同客户端版本菜单位置可能不同。
4. 粘贴全文，点击编辑器的**测试/编译**。顶部 `PN:=2;` 等为公式内赋值，不需要另外建立同名参数。
5. 编译成功后保存，在K线主图选用该指标。建议先加载至少300根历史K线，日线可从默认设置开始。

`.txt` 是公式源码，不能通过改扩展名冒充期货通的二进制导入文件。不要把Python文件放入公式编辑器。

如果完整公式编译报函数错误，可在另一个临时主图指标中使用 `函数兼容检查_UTF8.txt` 定位目标版本支持的函数。该文件只供兼容核对，不是交易指标。反馈完整错误行及客户端版本，才能准确判断版本差异。

## 看图

| 显示 | 含义 |
|---|---|
| 青色折线 | 细尺度已确认转折；默认右侧2根确认 |
| 黄色粗折线及转折价 | 工作尺度已确认转折；默认右侧7根确认 |
| 最新一段连至当前收盘价 | 进行中预览，当前K线未收盘时会变化 |
| 青色/白色Q数字 | 从相应极值到首次收盘越过的实际K线根数；青色为细Q，白色为工作Q，起始根不计 |
| Q同级/扩张/收缩/升级候选/降级候选 | 相邻同方向收盘Q的比较，不能单独证明五/七浪完整 |
| 黄色水平价位线 | 调整/横盘时的0%、23.6%、38.2%、50%、61.8%、78.6%、100%回调尺 |
| 橙色水平价位线 | 顺势推进时最近三个未触及的H1候选目标；不会同时画回调尺 |
| 趋势参考、拐点平移参考 | 当前锚点直线段与对边斜率平移观察，最长SPAN根，未完成严格包络验证 |
| abc、三角、A? | 候选观察，不能作为书中已经确认的调整或分界 |
| 关键位置看涨/看跌·候选 | 上一根已知回调位置附近形成标准大小的反转形态 |

主图标题数据中“工作方向”：`1`上升、`-1`下降、`0`待确认。“方向模式”：`0`自动、`1/-1`人工指定；“末段状态”：`1`顺势、`2`调整、`3`横盘、`0`待确认。转折边的价格是实际高/低点价，不代表真实成交或已执行止盈。

**历史回标会重绘。** 转折经过右侧确认后才画回极值所在K线，`BACKSET`/`POLYLINE`负责这部分图形；`REFX1`只冻结当前价位尺并向左画短线。它们全部位于独立绘图段，不参与上游方向、Q、标准K和反转的计算。最后一根未收盘K的“收破”和形态仍是盘中预览，应在收盘后确认。不要用静态历史图上的回标位置冒充当时已知的信号。

## 常用设置

修改公式最上面的数值后重新测试、保存。无需修改后面生成的40根排序表达式。

| 设置 | 默认 | 用途 |
|---|---:|---|
| `PN` | 2 | 细尺度转折右侧确认根数，整数≥1 |
| `BN` | 7 | 工作尺度转折右侧确认根数，整数且大于PN |
| `DIR` | 0 | 0自动；1人工指定上升工作方向；-1下降 |
| `KIND` | 0 | 0自动；1人工指定顺势；2调整；3横盘 |
| `SPAN` | 90 | 最后价位尺最多向左显示的K线根数，整数≥1 |
| `SHOWQ/SHOWK/SHOWF/SHOWT/SHOWC` | 1 | 区间/反转/回调尺/目标/结构参考开关；0关闭 |
| `DETAIL` | 0 | 1显示更多历史Q文字及端价；0精简显示 |
| `MANF` | 0 | 1启用人工核定的前主浪起止点；0使用自动工作段/横盘完整腿候选 |
| `MFROM/MTO` | 0/0 | MANF=1时，前主浪的起价/止价，允许负数和0 |
| `MFAGE` | 90 | MANF=1时，前主浪起点距最新K线的实际根数，不能超过已加载历史 |
| `MH1` | 0 | 0使用自动H1候选；正数使用人工核定的同级浪1高度 |
| `MBASE` | 0 | 人工H1模式的前调整结束价；允许0和负数 |
| `MORG` | 0 | 人工H1模式的浪1起点价；3.236/4.236目标从此投射 |
| `MAGE` | 0 | 人工H1模式的前调整结束点距今根数，整数≥1且小于已加载根数 |
| `STRONG` | 0 | 1才允许额外2.382/2.618/3倍强势目标，需人工判断是否具备强势条件 |

自动工作尺度取转折确认跨度，不等于原书以Q归属确定的完整级别。自动范围偏细时应调整BN或使用人工锚点，不能直接把最新几处局部转折当作完整主浪。

例如下降主浪 `3919.71 → 3174.45` 后正在反弹：设置 `DIR:=(0-1); KIND:=2; MANF:=1; MFROM:=3919.71; MTO:=3174.45;`，再把 `MFAGE` 改为该主浪起点距今的实际根数。0%在3174.45，100%在3919.71，50%为3547.08，61.8%为3635.02。只画回调尺。若要覆盖前浪更长范围，同时调大SPAN。手动输入负数也使用类似`(0-100)`的写法。

前一主浪尚未走完时，不能把盘中极值填作“已完成前浪”。人工修改方向或锚点后，整张图会采用新设置，旧标注不代表过去当时采用的参数。

MFAGE/MAGE是相对最新K线的距离，适合固定历史位置核对。新增K线后，人工模式需相应增加该根数，否则统计起点会前移；加载更多历史也应复核锚点是否仍在范围内。默认自动模式会随行情重新选择候选，不需要维护这两个手动距离。未采用未经核对的日期函数来伪造固定时间锚点。

## 源码与复查

- `generate.py`：生成两种编码的主图及兼容检查公式，Python 3.11+，仅标准库。
- `compatibility.py`：将数学模板转为COUNT数值标志、有限数值选择和颜色参数；限制REF边界并生成短变量名。模板中的IF仅用于描述数学选择，不能直接安装。
- `变量映射.json`：数学模块原变量名到导出短名的对照。
- `check_formula.py`：本地解析器、函数调用检查和数值解释器；不是同花顺官方编译器。
- `tests/test_indicator.py`：标准K、Q、方向破位、完整工作段、互斥、短历史、端点与标注密度回归；需NumPy。
- `plot_audit.py`：执行导出绘图AST的本地几何检查；可选Matplotlib生成合成数据预览，不能替代原生客户端。
- `docs/previews/synthetic_fall_rebound.png`：合成长期下降后反弹的几何预览。
- `tests/fixtures/v1_0_2_math_reference.txt`：旧版本数学对照，不是安装公式，不能粘贴到客户端。
- `docs/本地检查结果.json`：实际运行的静态检查报告。
