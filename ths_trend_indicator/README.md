## 标注内容

黄线M、浅蓝P、青色S均以所属区间选点：白色Q跨度与根数、1浪2浪等浪号、相对前一同级推进腿的RET%、实际主浪端点的H1倍数、转折附近完成根上的RV形态，以及紫红调整结构a…e。

主浪端点标的是**实际高度/H1，保留三位小数**，不是端价，也不是把结果吸附到1.618等候选倍数。H1须来自该组第一推进与首个收盘Q；依据不足显示H1 ?。价格尺的高低锚点另显示实际价格及十字标记。

Q不是把每一个细拐点依次编到11浪。第一Q用收盘首次越过原高低，以后可用影线，起始根不计。同级延续、升级/降级、包容、调整破位及1.618高度延长先处理，再给5/7结构编号。合并重新查真实极值和首次越过，不能直接相加原区间根数。两同级Q标5 EQ；三Q按EXP/CON/DIA/X分类。abc末点取c、三角/abcde取e，不能用较早的极端a替代。

M和P通过同一主浪的实际边界建立归属，P内部小高低点不再截短父段。当前回调从该P末点开始，EWT03不展开历史回调。详细英文代码见[图例](docs/ASCII图例对照.md)。

## 黄金分割与止盈

| 行情及末段 | 显示 |
|---|---|
| 趋势主浪 | 有同级H1依据时，最近三个未触及候选止盈位；不画分割 |
| 趋势回调 | 前一完整主浪的黄金分割；不画趋势止盈 |
| 震荡 | 前一完整波段的黄金分割；不画趋势止盈 |

分割0%在前浪末端，100%在前浪起点。前浪下跌、当前反弹时，下0%上100%；前浪上涨、当前下调时相反。人工MANF锚点优先；指定末端在实际行情中找不到时不伪造结束日期或P轮廓。

1. 解压备份，从主图移除旧指标，停止使用旧EWT04。
2. 指标管理中新建或打开EWT01，选择主图叠加、保存至本地；说明和外部参数表留空。
3. 用`formulas/install/EWT01.txt`全文替换、测试保存；EWT02、03同样操作，再加载这三层。
4. 文件为UTF-8无BOM，复制全文。EWT02保留紧凑排版与Windows换行；勿另存成ANSI或逐句自动换行。`EWTN_ASCII.txt`是超长开发参照，不能直接安装。

内部变量使用紧凑名称，显示代码仍为英文。各文件按Windows CRLF计数控制在79500以内；字节数可大于字符数。80000通过/80001拒绝是2026-11-05官方保存服务的实测观察，不是永久编译器承诺。最终文件是否通过实际内容校验，以本版检查记录为准。

## 检查与边界

各层最多输出三个同级Q的5/7结构；M/S各检查三个候选Q，P检查五个，再重新分级和合并。超过范围或有第四个同级Q待归属时显示Q EXTENSION?，不把有限搜索冒充无限递归。多转折形态证据不足保留COMPLEX?/ADJ?，不强行套形态。转折数浪是当前末端回顾解释，新K线可能重绘；实际H1端点倍数描述已观察走势，未来只给候选。

[验证记录](docs/验证记录.md)区分本地回归、官方5.4.0.5离线解析与合成计算、公开源码的官方保存内容校验。**目标4.39.1.2界面未运行；公式自动消失的机制未确认。** 包内不含专有DLL/EXE，不执行交易。合成预览不等于用户行情复原，自动分级也不保证是唯一书本解释。

依据用户指定第三版3.pdf，原函数导出完整保存在`reference/all_func.json`。主要实现为`hierarchy_scope.py`、`interval_engine.py`、`interval_render.py`、`interval_prices.py`、`interval_layers.py`；`native_layers.py`导出三个自足安装文件。旧版分组入口保留用于历史/核心回归；Builder和Q比较辅助由新版复用。
