# 趋势交易 · 同花顺期货通电脑版结构观察版 1.0.3

这是一套可复制到**期货通电脑版自编技术指标编辑器**的主图公式，适用于不同期货品种和K线周期。公式不依赖天勤、Python或账号登录。本包同时附上生成源码、静态检查器和数值测试，方便检查和修改。

**这次交付是公式观察版，并非原Python指标的完整移植。** 已实现双尺度转折连线、收盘突破Q、区间比较、回调百分比、末段黄金分割/候选目标互斥、标准K及部分反转形态、调整与A点候选。原程序的父子孙归属、完整五/七浪数法、内外/失败Q、全部调整浪和严格分界确认尚未移入本公式，因此不标“完整五子浪已确认”，也不把普通局部点标成正式A点。详细范围见[实现范围](docs/实现范围.md)。

**已完成本地语法静态检查和数值测试；尚未在期货通客户端实际编译。** 云环境没有Windows期货通客户端，官网在线帮助亦未能访问。公开公式示例仅用于交叉核对部分调用，不能替代目标版本的编译结果。见[函数核对](docs/函数核对.md)和[验证记录](docs/验证记录.md)。

**1.0.3兼容修订的目标版本是用户提供的4.39.1.2。** 1.0.2改写负数后仍在第166行报错，说明上次处理没有解决该处解析问题。本版把该行拆成两个简单判断和一条数值赋值，符号由`2*标志-1`计算；主图不再输出AND/OR条件组合。组合条件先转换为0/1，再用乘法/MAX组合，必要时放到中间变量后供IF、绘图等函数引用。IF分支不直接放负数常量。54项本地检查通过，且与1.0.2分析数值逐项对照一致；**仍未在4.39.1.2客户端实际编译**。

原第166行的替代逻辑为：

```text
TTSNOLOW:=IF(TTSLS=0,1,0);
TTSNEWH:=IF(TTSHT<TTSLT,1,0);
TTSTYPE:=2*TTSHS*MAX(TTSNOLOW,TTSNEWH)-1;
```

后续另一尺度和其他组合条件同步修订，因此请用新版全文替换，而非仅修改这三行。这是更保守的输出子集，不能据此宣称该客户端普遍不支持AND、OR或负数。

保留1.0.1的修复：1.0中的`SK`与期货交易指令冲突，标准K已使用`TTSTD`，其他内部变量统一使用`TT`前缀，顶部设置名称保持不变。标准K与目标排序显式使用`IF(条件,1,0)`转数值，并有条件/数值类型检查。

升级时请先清空旧指标正文，再粘贴新版**全部公式**，不能只修改报错的一行，因为后续引用也已同步更名。若之前调过PN/BN等顶部设置，可按原值重新填写。

## 安装

1. 解压整个压缩包。
2. 用Windows记事本打开 `formulas/趋势交易_PC主图_UTF8.txt`，全选并复制。若文字乱码，使用对应的 `GB18030.txt`；两份公式内容相同。
3. 在期货通电脑版找到**公式管理/自编指标**，新建**技术指标**，选择**主图叠加**，名称可填“趋势交易观察”。不同客户端版本菜单位置可能不同。
4. 粘贴全文，点击编辑器的**测试/编译**。顶部 `PN:=2;` 等为公式内赋值，不需要另外建立同名参数。
5. 编译成功后保存，在K线主图选用该指标。建议先加载至少300根历史K线，日线可从默认设置开始。

`.txt` 是公式源码，不能通过改扩展名冒充期货通的二进制导入文件。不要把Python文件放入公式编辑器。

如果完整公式编译报函数错误，可在另一个临时主图指标中使用 `函数兼容检查_UTF8.txt` 定位目标版本支持的函数。该文件只供兼容核对，不是交易指标。反馈完整错误行及客户端版本，才能准确判断版本差异。

主图标题数据中“工作方向”：`1`上升、`-1`下降、`0`待确认。“末段状态”：`1`顺势、`2`调整、`3`横盘、`0`待确认。转折边的价格是实际高/低点价，不代表真实成交或已执行止盈。

**历史回标会重绘。** 转折经过右侧确认后才画回极值所在K线，`BACKSET`/`DRAWLINE`负责这部分图形；`REFX1`只冻结当前价位尺并向左画短线。它们全部位于独立绘图段，不参与上游方向、Q、标准K和反转的计算。最后一根未收盘K的“收破”和形态仍是盘中预览，应在收盘后确认。不要用静态历史图上的回标位置冒充当时已知的信号。

## 常用设置

修改公式最上面的数值后重新测试、保存。无需修改后面生成的40根排序表达式。

| 设置 | 默认 | 用途 |
|---|---:|---|
| `PN` | 2 | 细尺度转折右侧确认根数，整数≥1 |
| `BN` | 7 | 工作尺度转折右侧确认根数，整数且大于PN |
| `DIR` | 0 | 0自动；1人工指定上升工作方向；-1下降 |
| `KIND` | 0 | 0自动；1人工指定顺势；2调整；3横盘 |
| `SPAN` | 90 | 最后价位尺最多向左显示的K线根数，整数≥1 |
| `SHOWQ/SHOWK/SHOWF/SHOWT/SHOWC` | 1 | 区间/反转/回调尺/目标/结构参考开关；0关闭 |
| `MANF` | 0 | 1启用人工核定的前主浪起止点；0使用自动工作腿候选 |
| `MFROM/MTO` | 0/0 | MANF=1时，前主浪的起价/止价，允许负数和0 |
| `MFAGE` | 90 | MANF=1时，前主浪起点距最新K线的实际根数，不能超过已加载历史 |
| `MH1` | 0 | 0使用自动H1候选；正数使用人工核定的同级浪1高度 |
| `MBASE` | 0 | 人工H1模式的前调整结束价；允许0和负数 |
| `MORG` | 0 | 人工H1模式的浪1起点价；3.236/4.236目标从此投射 |
| `MAGE` | 0 | 人工H1模式的前调整结束点距今根数，整数≥1且小于已加载根数 |
| `STRONG` | 0 | 1才允许额外2.382/2.618/3倍强势目标，需人工判断是否具备强势条件 |

自动工作尺度取转折确认跨度，不等于原书以Q归属确定的完整级别。自动范围偏细时应调整BN或使用人工锚点，不能直接把最新几处局部转折当作完整主浪。

例如下降主浪 `3919.71 → 3174.45` 后正在反弹：设置 `DIR:=(0-1); KIND:=2; MANF:=1; MFROM:=3919.71; MTO:=3174.45;`，再把 `MFAGE` 改为该主浪起点距今的实际根数。0%在3174.45，100%在3919.71，50%为3547.08，61.8%为3635.02。只画回调尺。若要覆盖前浪更长范围，同时调大SPAN。手动输入负数也使用类似`(0-100)`的写法。

前一主浪尚未走完时，不能把盘中极值填作“已完成前浪”。人工修改方向或锚点后，整张图会采用新设置，旧标注不代表过去当时采用的参数。

MFAGE/MAGE是相对最新K线的距离，适合固定历史位置核对。新增K线后，人工模式需相应增加该根数，否则统计起点会前移；加载更多历史也应复核锚点是否仍在范围内。默认自动模式会随行情重新选择候选，不需要维护这两个手动距离。未采用未经核对的日期函数来伪造固定时间锚点。

## 源码与复查

- `generate.py`：生成两种编码的主图及兼容检查公式，Python 3.11+，仅标准库。
- `compatibility.py`：内部变量命名及条件/数值转换，避免交易指令冲突与隐式转换。
- `check_formula.py`：本地解析器、函数调用检查和数值解释器；不是同花顺官方编译器。
- `tests/test_indicator.py`：独立排序、价格例子、Q边界、前缀一致性等回归；数值测试需NumPy。
- `tests/fixtures/v1_0_2_math_reference.txt`：旧版本数学对照，不是安装公式，不能粘贴到客户端。
- `docs/本地检查结果.json`：实际运行的静态检查报告。

复查命令：

```text
python generate.py
python check_formula.py
python -m pip install "numpy>=1.26"
python verify.py
```
