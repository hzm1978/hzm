# 趋势交易 · 同花顺期货通电脑版 1.3.0

按用户4.39.1.2导出的完整函数库制作，使用期货通本身行情，适用于不同品种及周期。运行指标不需要Python或账号。

三份安装文件已通过本地166项回归、90个原生合成指标实例及公开副本的12项官方保存内容检查，记录随包提供；目标客户端4.39.1.2界面仍未运行。

本版修正合并区间时移动原起点、以较早极端a替代实际c/e、后来的反弹高点替换整段前高，以及有效内部区间被长直线覆盖的问题。先找有效Q，再分级和数浪；原起点保留，合并后的返回计时从实际调整末点之后重新检查。只有影线摆动、没有实际反向收盘推进的小区间留在主浪内部。

| 文件 | 显示范围 |
|---|---|
| EWT01 | 最新主级M结构及完整信息 |
| EWT02 | 所选主级完整推进窗口内的P结构，保留有效内部区间及当前反向结构；主级价格尺 |
| EWT03 | 最后一段P主浪或回调的内部S结构；S末段回调时附前一完整S主浪分割 |

全文替换EWT01、02、03，移除旧EWT04，三层参数同步。原有英文区间分类保留。私有变量和全语句紧凑排版用于控制保存长度；**三份TXT均为UTF-8无BOM、Windows CRLF，勿逐句自动换行或另存ANSI。**

## 标注内容

黄线M、浅蓝P、青色S显示所属范围内的浪号、Q跨度和根数、相对前一同级推进腿的RET%、实际端点的H1倍数、转折附近完成根上的RV形态，以及紫红调整形态a…e。普通字为11号，主要浪号13号；各级文字分开放置。

主浪端点的数字是**实际推进高度/H1，保留三位小数**，不是端价，也不吸附到1.618等目标倍数。H1须来自该组第一推进与首个收盘Q；依据不足显示H1 ?。分割锚点另标真实价格及十字。

第一Q用收盘首次越过原高低，以后可用影线，起始根不计。先处理同级延续、升级/降级、包容及高度延长，再编同级3/5/7浪。合并保留左侧原根，返回时刻在实际c/e之后查找；不是相加原Q根数，也不是在整个区间另找一个更晚的起点。两同级Q标5 EQ，三Q按EXP/CON/DIA/X分类；未闭合或关系未定时保留问号，不硬凑五浪。

降级但有效的内部Q以小写`q LEN`、`q RET%`和白色虚线保留，并加入蓝色轮廓；它们不占用额外P浪号或独立H1。已被紫红a…e覆盖的内部调整不重复画一套q。abc末点取c，三角/abcde取e，不能用较早更极端的a替代。

最后一浪允许略低于前高或略高于前低，显示`TRUNC?`候选；不能仅因没有创新高低就删掉整段。分割尺仍保留该完整窗口实际最高/最低锚点，不把稍低的候选终点或后来的反弹高点当成原前高。

EWT03兼容最后一段P主浪和回调。很小的P尖端反应先作为该段S回调，已有有效返回Q或幅度达到前完整P段23.6%时才切换为独立P回调的S窗口；23.6%及截短候选的接近容差是自动量化约定，并非书本硬规则。可用DIR、KIND、MANF核定范围。

## 黄金分割与候选止盈

| 行情及末段 | 显示 |
|---|---|
| 趋势主浪 | 有同级H1依据时，最近三个未触及的候选目标 |
| 趋势回调 | 前一完整推进段的黄金分割 |
| 震荡 | 前一完整波段的黄金分割 |
| S末段回调 | EWT03另画前一完整S主浪灰色虚线尺 |

分割为0、19.1%、38.2%、50%、61.8%、78.6%、100%。0%在前浪末端，100%在前浪起点；前浪下跌时下0%上100%，前浪上涨时相反。S尺用整个所属S推进区间，不只量最后一条小腿。人工MANF锚点优先；指定末端在行情中不存在时不伪造日期和轮廓。

止盈分两种书本基准，**倍数不可直接按大小比较价格远近**：

- `LEG 1.208/1.618/2H1?`：最近同级调整末点 ± 倍数×H1，推算下一主浪高度。
- `LEG 2.382/2.618/3H1?`：强势候选；STRONG=1，或当前收盘已越过该腿2H1后启用。
- `TOTAL 3.236/4.236H1?`：浪1起点 ± 倍数×H1，推算整段趋势总高度。

例如下跌H1=200、调整末点3500、浪1起点4000：LEG 2H1=3100，TOTAL 4.236H1=3152.8，确实可能很接近。本版明确分开标签位置、显示价格，并在结构快照记录各自起算点。它们是候选位置，不代表确定反转或自动止盈指令。

`SHOWL:=1`显示有有效锚点且通过包络检查的趋势线TL?和拐点线PL?；后者取浪1→浪3外侧斜率，平移至浪2，不是随意复制趋势线。支持线在局部等价极值的平台末根取锚，Q和浪号仍标首次极值；收盘破坏后的参考线隐藏。`SHOWL:=0`可关闭，两种线都不改变数浪。

## 安装与参数

1. 备份旧公式，从主图移除旧指标，停止使用EWT04。
2. 指标管理打开EWT01，选主图叠加、保存至本地，说明和外部参数表留空。
3. 用`formulas/install/EWT01.txt`全文替换、测试保存；EWT02、03相同，再加载需要的层。
4. 按原排版粘贴TXT。`EWTN_ASCII.txt`是超长开发参照，不可直接安装。

| 参数 | 默认 | 说明 |
|---|---:|---|
| GN / PN / BN | 1 / 2 / 7 | 种子/细确认/父级确认，须1≤GN<PN<BN |
| DIR | 0 | 自动；1上涨，0-1下跌 |
| KIND | 0 | 自动；1主浪、2回调、3震荡 |
| BOOKBARS / SPAN | 600 / 90 | 结构搜索范围 / 止盈线跨度 |
| SHOWSUB / SHOWGRAND | 1 / 1 | P / 最后一段P内的S |
| SHOWQ / SHOWK / SHOWF / SHOWT / SHOWC / SHOWL | 1 | 区间 / K形态 / 分割 / 目标 / 调整 / 趋势及拐点线 |
| MANF | 0 | 1使用人工前浪锚点 |
| MFROM / MTO / MFAGE | 0 / 0 / 90 | 前浪起价 / 末价 / 起点距最新根数 |
| MH1 / MBASE / MORG / MAGE | 0 | 人工同级H1 / 调整末价 / 浪1起价 / 调整末点距今 |
| STRONG | 0 | 人工开启额外强势候选 |

负方向写`DIR:=0-1;`，整个右侧不再加括号；人工年龄随新增K线维护。各文件按CRLF计数控制在79500以内。80000通过、80001拒绝是官方保存服务实测现象，不是永久编译器承诺；当前字数、哈希及保存检查以本版报告为准。

## 检查与边界

同级最多三个Q；M/S各检查三个候选Q，P检查五个。超过范围或第四同级Q待归属显示Q EXTENSION?。复杂形态证据不足保留COMPLEX?/ADJ?。数浪是当前末端回顾解释，新K线可能重绘，自动解释不保证唯一。

[验证记录](docs/验证记录.md)分别列出本地回归、官方5.4.0.5离线解析及合成计算、公开源码的官方保存检查。**目标4.39.1.2界面未运行，自动删除公式的机制尚未确认。** 包内没有专有DLL/EXE。合成场景根据问题特征设计，未获取截图对应OHLC，不冒充用户行情复原。

书本依据为用户指定第三版3.pdf，完整函数导出保存在`reference/all_func.json`。实现入口为`hierarchy_scope.py`、`interval_engine.py`、`interval_render.py`、`interval_prices.py`、`interval_guides.py`和`interval_layers.py`，由`native_layers.py`导出三个自足安装文件。旧分组仅用于明确隔离的历史回归。

开发复查需Python3.11+、NumPy，预览另需Matplotlib；安装不需要这些。

```text
python -m pip install numpy matplotlib
python verify.py
python inspect_structure.py --scenario q_reversal --output structure.json --preview preview.png
python inspect_structure.py --csv candles.csv --output own_structure.json
```

CSV按时间升序，列O/H/L/C或open/high/low/close。快照提供M/P/S范围、有效内部Q、长度/RET/H1、当前P反向结构、两类分割锚点、目标起算点及参考线状态。
