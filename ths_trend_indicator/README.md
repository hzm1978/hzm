# 趋势交易 · 同花顺期货通电脑版 1.1.3

依据用户从 **4.39.1.2** 导出的 `all_func.json` 制作的原生主图公式。包含波浪连线、Q区间跨度、子浪回调百分比、调整形态、分界A、转折K线观察，以及互斥的候选止盈线/黄金分割线。使用期货通自身行情，适用于不同品种与周期。

本版针对EWT02运行慢、连线缺失和文字拥挤重组安装层：**EWT01显示主浪与工具，EWT02完整显示当前段及前一段子浪和价格尺，EWT03仅在需要孙浪时追加**。前两个已包含通常需要的大浪及下一级子浪，不再要求加载旧版四层。

计算上，工作末端的区间扫描只在最后一根执行，再广播给历史绘图，避免每根重复扫描。原生内核对`FILTER(BACKSET(...),N)`的嵌套处理与先保存回标序列的结果不同，本版将BACKSET先存变量，修正多余转折点。KTEXT与数字统一按原生对齐定义定位，使用9号字；含义与数值分别落在锚点两侧。具体证据见[官方解析检查说明](docs/官方解析检查说明.md)。

三个安装文件均小于79,000 ASCII字节，给实测的80,000字符保存校验边界留出余量。完整`EWTN_ASCII.txt`保留供开发复查，**不要整份粘贴安装**。旧版将图形按长度任意拆开，导致只加载前两层时缺线；新版按功能归组，同一子浪的线、Q、回调数字和标签在同一文件内。

本包分别记录本地数值/几何测试、官方5.4.0.5解析器离线语法与实际计算、官方内容服务校验。六组合成场景逐一核对三个安装文件的原生线段坐标和标注，并保存原始结果。**解析器版本不同于您使用的4.39.1.2，尚未运行该版本界面，也未复现自编公式消失的过程。** 详细结果和哈希见docs中的JSON。

## 安装

1. 解压整个包，在修改客户端公式前保留这份源码备份。
2. 公式管理/自编指标→新建技术指标，名称填**EWT01**，类型选**主图叠加**，保存位置选**本地**，说明和外部参数表留空。只粘贴`formulas/install/EWT01.txt`全文，测试后保存。
3. 同样创建**EWT02**，粘贴同名TXT。在同一K线主图加载**新版EWT01和EWT02**，移除旧EWTN/EWT01～EWT04，避免重复。不要拼接文件，不要继续加载旧四层。
4. 需要更细一级时，再创建和加载**EWT03**。它只负责孙浪；没有符合条件的孙结构时可以没有输出。

先用默认参数。每份首行均为`PN:=2;`，无需另建同名参数。三个安装文件为ASCII，在UTF-8和ANSI/GB18030下字节相同。运行指标无需Python、天勤或交易账号。

各层独立计算，无跨指标数据依赖。修改GN/PN/BN、DIR、KIND、人工锚点或其他参数时，所有已加载的新层必须一致。安装版固定书本显示`SHOWBOOK=1`、简洁模式`DETAIL=0`，这两项不再放入安装正文；基础/详细开发对照保留在完整模型中。

“自编公式也消失”已作为独立故障记录，原因尚不能确认。官方现行SDK存在云端缓存清理本地模型的路径，但这不足以认定用户现场原因，更不能认定是计算慢触发删除。选择本地保存并保留ZIP内TXT作为备份；若再消失，源码可以恢复。

两套价格尺互斥。历史工作转折旁保留一项实际到达价格。标题XWD为工作方向：1上升、-1下降、0待定；XPH为末段状态：1顺势、2调整、3横盘；XRDIR为价格尺方向。其余图例用语可查独立中文对照表。

趋势线连接工作起点与终端极值之前的合适调整点，检查锚间穿价；拐点线另用对边外延线斜率平移并检查包络。直接收破观察检查标准大小、距离、深度和结构，否则使用突破根及后两根的延时水平；后续创新极值会过滤延时解释。

## 搜索范围

搜索采用最近BOOKBARS根，每组最多8个交替端点。主级下面展开当前段和前一段的子结构，再展开最近有效子结构末段的孙结构。Q负责检验计数；GN/PN/BN提供取点，不直接等同于原书级别。

调整识别覆盖简单、标准/收缩/强势abc、收缩/扩张三角、趋势/横向/不规则abcde，以及有内部收盘Q和路径包络证据的复杂1-3-1候选。更长复杂组合、两个三角的钻石/X调整组合、失败Q重分级、无限历史递归和Tp/Ta时间目标仍需人工核对。五/七浪的钻石/X与同名调整组合是不同结构。

原书允许多种合规数法，图上采用“结构解释/候选”。同级H1证据不足时显示依据不足；本组目标全被触及时保留本组依据并显示状态。详细边界见 [实现范围](docs/实现范围.md)。

## 参数

在所有已加载的新指标中同步修改最上方的数值，再分别测试保存。

| 参数 | 默认 | 用途 |
|---|---:|---|
| GN/PN/BN | 1/2/7 | 孙/子/工作取点右侧确认根数，整数且1≤GN<PN<BN |
| DIR | 0 | 0自动，1指定上涨，`0-1`指定下跌 |
| KIND | 0 | 0自动，1顺势，2调整，3横盘 |
| BOOKBARS | 600 | 当前结构搜索的实际K线根数 |
| SPAN | 90 | 价格尺及参考线最多向左显示的根数 |
| SHOWSUB/SHOWGRAND | 1/1 | 子/孙结构显示开关 |
| SHOWQ/SHOWK/SHOWF/SHOWT/SHOWC | 1 | Q/反转/回调尺/目标/结构工具开关，0关闭 |
| MANF | 0 | 1使用人工核定前完整浪的锚点 |
| MFROM/MTO/MFAGE | 0/0/90 | 人工前浪起价/止价/起点距最新K的根数 |
| MH1 | 0 | 正数使用人工核定同级浪1高度，0自动 |
| MBASE/MORG/MAGE | 0/0/0 | 人工H1的前调整末价、浪1起价、调整末点距今根数 |
| STRONG | 0 | 人工开启强势条件后增加2.382/2.618/3倍候选 |

人工指定下降请写`DIR:=0-1;`，不要把整个赋值右侧写成`(0-1)`；现行内核会把后一种写法算成空值，原生小样已记录。人工价格允许0与负数。MFAGE/MAGE须在加载历史内，MAGE≥1；它们是相对距离，新增K后需维护。自动模式随当前前缀更新。

例如前下降浪3919.71→3174.45后正在反弹，可指定 `DIR:=0-1; KIND:=2; MANF:=1; MFROM:=3919.71; MTO:=3174.45;`，再设置实际MFAGE。50%为3547.08，61.8%为3635.02，回调尺保留前浪完整起止位置。

## 确认时间

标准K、方向观察、原始Q、形态与关键位置属于因果分析段；绘图段使用末值冻结、回标与位移，后续K线会使解释重选。导出配置.json保存两段的物理行边界，安装文件本身不夹带开发标记或注释。浪号画回实际极值的位置不能当作当时已知的交易信号。

末根未收盘时的收破、形态和目标触及属盘中预览。指标不发交易指令。A确认、A失守与工作方向观察各有独立状态，局部A失守不会无条件改为父趋势反转。

## 源码与复查

- generate/compatibility：生成、条件数值转换、REF边界和安全短变量名。
- export_native：原生粘贴文本校验、全ASCII标签、无注释/无BOM输出及分段旁表；模型中的花括号注释只供开发，不输出给客户端。
- native_layers：按功能生成两份推荐层及一份可选孙浪层；裁剪依赖、保留可编辑设置，嵌套IF和BACKSET先存中间变量。
- book_layers/corrections/lines/prices、candle_patterns：结构、调整/A、画线工具、价格尺与K线形态。
- reference/all_func.json、catalog：用户函数库原样文件及定义读取；其中示例只作资料，未执行代码或交易示例。
- check_formula/catalog_math/plot_audit：本地解析、数值模型、绘图几何复查，独立于官方编译器。
- native_preparse：官方解析器的离线语法和绘图描述检查。
- native_runtime/native_scenarios：在合成OHLC上离线执行官方计算内核，并逐项比较实际线段、标注坐标和对齐；拒绝交易/外部数据公式，不启动客户端、不联网、不登录，包内不附带官方DLL。
- tests：独立排序、实际Q事件扫描、四类七浪耦合、合并、归属、三角e、A状态及价格尺回归。
- inspect_structure：输出结构、Q起止/长度、归属、回调、A确认位置及全部H1目标状态。
- 变量映射.json、结构字段.json、导出配置.json：模块字段、短变量、实际文件哈希与分段边界。
- docs：函数依据、检查记录、六组合成预览和对应JSON明细。

Python 3.11+，在本目录运行：

```text
python -m pip install "numpy>=1.26"
python verify.py
python inspect_structure.py --scenario fall_rebound --output structure.json
python inspect_structure.py --csv candles.csv --output own_structure.json
python -m pip install matplotlib
python inspect_structure.py --scenario seven_expanding --output seven.json --preview seven.png
```

CSV按时间升序，列名O/H/L/C或open/high/low/close；bar_index从0起指向实际行。检查工具读取给定数据，不连接期货通或账号。
