# ASCII图例中文对照

黄线1、2…是主级Q结构解释；浅蓝P是整段连续走势；青色回调S只在可选EWT04中显示。E1./E2.为较早第1/2段完整主浪的子结构。Q为区间根数，RET%为相对前一推进腿的回调比例。
RV为形态编号；B/S区分对应的看涨/看跌几何。OBS是转折观察，KEY还要求标准大小与关键位置。
文字改为ASCII用于兼容客户端保存过滤，数浪、价格和确认条件保持不变。
