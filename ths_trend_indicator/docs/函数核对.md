# 函数与语法核对

目标是同花顺期货通电脑版4.39.1.2的自编技术指标主图。以下是本包的本地配置与来源，**不是官方编译器规范**。

## 1.0.5所依据的现场结果

用户已在4.39.1.2确认四行COUNT小样编译通过，并发来源码和显示曲线的截图：

```text
QFLAG:=COUNT(C>O,1);
QOTHER:=COUNT(C<O,1);
QSIGN:=MAX(QFLAG,QOTHER)+QFLAG-QOTHER-1;
检查:QSIGN;
```

这确认COUNT(条件,1)返回的数值可以参与MAX、加减和变量引用。它不验证完整主图、乘法组合或其他绘图函数。首次小样的乘号复制丢失问题及旧版失败证据见 [客户端核对](../diagnostics/README.md)。

1.0.4统一IFELSE后，用户仍反馈完整公式失败。当前没有证据足以断言客户端如何展开变量或IF/IFELSE唯一失败原因。因此1.0.5选择已获现场证据的COUNT数值标志作为转换基础，**整份导出不再调用IF/IFELSE**：比较变为COUNT(比较,1)；AND用0/1乘积，OR用MAX；有限数值选择用m*A+(1-m)*B。m严格为0或1。

这个替换要求两分支均为有限数值。0乘空值仍可能为空值，故转换器拒绝NULL/DRAWNULL进入数值选择。主图不使用空价位，而用条件DRAWLINE绘制回调尺、目标和当前锚点参考线，关闭时不画，也不输出0价曲线。REF距离显式限制在0至BARPOS-1；负的常量REF在转换前直接拒绝。

生成器中的IF只描述数学模型，不是可粘贴到客户端的安装源码。检查器可解析公开示例的IF与IFELSE，并不把它们普遍认定为非法；导出层的零条件函数要求由专门测试核对。

## 采用的函数形态

| 函数 | 本包写法 | 使用范围与依据 |
|---|---|---|
| COUNT | COUNT(条件,N) | N=1作数值标志的四行组合已由用户原生确认；其他组合仍待主图验证 |
| ABS/MAX/MIN | ABS(X)、MAX(A,B)、MIN(A,B) | 1/2/2参数；MAX加减组合包含在通过小样中 |
| REF | REF(X,N) | N为非负整数，全部限制到可用历史；动态支持仍需客户端确认 |
| HHV/LLV | HHV(X,N)、LLV(X,N) | 2参数，动态窗口至少1根 |
| SUM | SUM(X,N) | 数值输入，N=0累计历史 |
| BARSLAST | BARSLAST(条件) | 配合累计事件数检查是否发生，未发生返回值不作为存在证据 |
| FILTER/BACKSET | FILTER(条件,N)、BACKSET(条件,N) | 仅绘图回标使用 |
| REFX1 | REFX1(X,100000) | 按公开示例冻结末值，仅绘图；越界行为仍待原生核对 |
| DRAWLINE | DRAWLINE(条件1,价1,条件2,价2,COLORCYAN) | 5参数，第五项为颜色，不是扩展标志0 |
| DRAWTEXT | DRAWTEXT(条件,价,'文字') | 3参数，颜色写在调用后 |
| DRAWNUMBER1 | DRAWNUMBER1(条件,价,数值,精度) | 4参数，颜色后缀；价格2位，Q根数0位，回调1位 |
| MA | MA(C,5) | 仅函数兼容检查文件使用 |
| BARPOS/ISLASTBAR | BARPOS、ISLASTBAR | 无括号；末根判断只用于绘图 |

主图不使用DRAWNUMBER；检查器也保留其公开示例中的5参数末项颜色签名，以防混用。主图不使用CON2STR、DRAWTEXT_FIX、DRAWSL、CONST、DLL或交易指令。

## 旧版失败记录与本地检查边界

- 1.0：SK被客户端识别为交易指令；标准K改名为TTSTD，内部名避开已知交易保留字。
- 1.0.1至1.0.3：调整负数/逻辑表达式仍被用户反馈失败，不能把这些改写当作已解决问题。
- 1.0.4：采用公开示例IFELSE及颜色签名后仍失败；公开示例不能覆盖用户现场结果。
- 1.0.5：已按通过的COUNT小样替换整条计算链；完整主图尚待原生测试。

本地检查包括定义/引用/保留名、标点与括号、函数参数数目和类型、条件/数值显式转换、负窗口、REF边界、除零保护、未来函数分析隔离、两种编码一致性及数学回归。64项测试通过，详见 [验证记录](验证记录.md)。

源码62963字节（UTF-8 BOM/CRLF），479变量、4个标题输出。64KiB、500变量和16个输出是本包自己的保守预算，并非声称官方限制。不能据此保证客户端的数量限制、动态窗口支持、绘图行为、字体遮挡或速度。最后仍以4.39.1.2实际编译和加载为准。
