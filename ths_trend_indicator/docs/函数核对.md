# 函数核对

1.1.1交付额外检查注释语法和文本字节。导出的操作符明确提供 // 和 /*...*/；此前开发解析器还接受花括号注释，不能据此认定原生支持。现在所有安装TXT均不含注释、BOM或隐藏格式字符。默认EWTN_ASCII.txt还将全部标签和标题字段改为可见ASCII简称，中文对照单独保存。

依据是用户导出的4.39.1.2 `reference/all_func.json`：286条记录、282个不同名称。同名按首条定义读取。文件SHA256及实际使用函数的完整签名、说明、参数与备注见 [使用函数核对.json](使用函数核对.json)。

| MAX1/MIN1、SIGN、INTPART、MA | 极值、方向、整数位置和ATR均值 |

DRAWLINE3在倒数第二根触发起点、末根触发终点，再位移到实际端点，避免假设同根两条件也能配对跨段。绘图函数不赋给变量。

标准K的40样本分20+20先各取5，再从10候选中选全局5，满足SORT容量限制。同实体近者优先，当前根排除，十字根方向距离为0；与独立排序核对。

COUNT(条件,1)转0/1，有限选择使用数值掩码；只有可能为空的查询保留函数库明确说明的IFELSE(ISNULL(...),...)。负数用二元减法分组，变量避开全部导出函数名和交易名称。

导出中没有字符串数字转换函数，文字和数值分开对齐。KTEXT使用内置位置与LCR参数，不附加未说明的字体样式；动态数字使用明确支持ALIGN/FONTSIZE的DRAWSHIFTNUMBER。检查器拒绝DRAWTEXT的非颜色后缀及KTEXT的后缀样式。

检查器拒绝未知函数、错误参数数目/类型、SORT超30项或可变模式/名次、REFX1可变N、重复/前向变量、负窗口及分析段未来绘图。256KiB源码、2048变量和16输出是项目自定审查预算，**不是官方限制**。完整原生编译、容量和速度待客户端核验。
