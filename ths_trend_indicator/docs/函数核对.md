# 函数核对

1.1.2补充官方现行解析器的离线语法与绘图描述检查。1.1.1的ASCII正文仍被用户报告首行错误和保存拦截，不能认定只是注释或编码问题。安装使用四份formulas/install/EWT01～EWT04.txt，全部无注释、BOM或隐藏字符并使用ASCII简称；完整EWTN_ASCII.txt只供开发复查。保存长度边界的实测记录与原生语法检查分别保留。

依据是用户导出的4.39.1.2 `reference/all_func.json`：286条记录、282个不同名称。同名按首条定义读取。文件SHA256及实际使用函数的完整签名、说明、参数与备注见 [使用函数核对.json](使用函数核对.json)。

| 函数 | 采用语义 |
|---|---|
| DRAWLINE(C1,P1,C2,P2,COLOR) | 两条件同根同时成立，画竖段；仅兼容示例使用 |
| POLYLINE(COND,DATA,COLOR) | 连续连接满足条件各根的DATA |
| DRAWLINE3(C1,P1,X1,C2,P2,X2,EXP) | 配对起点与其后最近终点，各左移X1/X2；EXP=0有限段，颜色后缀 |
| DRAWSHIFTNUMBER(COND,PRICE,NUMBER,PRECISION,COLOR,DIRECTION,X) | 仅兼容示例使用常量偏移；变量X原生报2012，套函数可产生无效绘图偏移，不用于主图动态标注 |
| DRAWNUMBER(COND,PRICE,NUMBER,PRECISION,COLOR) | 在目标K线上直接写数字，门限/年龄/价格/数值全部末值冻结，支持ALIGN/FONTSIZE |
| SORT/SORTPOS(Type,POS,N1…N30) | 最多30数据项，Type/POS常量，相等按输入顺序 |
| BARSSINCEN(COND,N) | N含当前根，查窗口首次成立年龄；N必须正数 |
| VALUEWHEN(COND,X) | 保存最近成立时的X；之前可为空 |
| HHVBARS/LLVBARS | 极值年龄，首根可为空；本地同值取近者，Q时钟另查首次 |
| ISNULL/IFELSE | 按导出ISNULL示例处理无事件；不把0乘NULL当有效选择 |

| HHV/LLV、COUNT/SUM | 动态窗口，N=0仅按相应函数说明使用 |
| BACKSET/FILTER | 仅绘图回标；FILTER N=0抑制其后全部触发 |
| DRAWTEXT | 三参数，字面文字，仅采用明确说明的颜色后缀 |

| DRAWNUMBER1 | 四参数，颜色后缀，区别于五参数DRAWNUMBER |
| MAX1/MIN1、SIGN、INTPART、MA | 极值、方向、整数位置和ATR均值 |

DRAWLINE3在倒数第二根触发起点、末根触发终点，再位移到实际端点，避免假设同根两条件也能配对跨段。绘图函数不赋给变量。

标准K的40样本分20+20先各取5，再从10候选中选全局5，满足SORT容量限制。同实体近者优先，当前根排除，十字根方向距离为0；与独立排序核对。

完整开发模型继续采用COUNT(条件,1)转0/1及数值掩码。安装图层保留条件类型，只有需要数值运算时才COUNT转换，并采用原生IF/IFELSE选择。官方解析器对MAX(1,IF(...))返回15，对先将IF存变量再MAX返回0，因此所有嵌套选择先存中间变量；不是将IF/IFELSE当成禁用函数。空查询保留明确选择，不以0乘NULL替代。负数用二元减法分组，变量避开全部导出函数名和交易名称。

导出中没有字符串数字转换函数，文字和数值分开对齐。KTEXT以位置0和LCR显示；动态数字使用DRAWNUMBER，按VX与冻结年龄相等的目标K线触发。检查器拒绝动态文字偏移、DRAWTEXT的非颜色后缀及KTEXT的后缀样式。颜色独立对照表明自定义COLOR返回附加信息但ErrCode为0，不将其作为错误禁用。

检查器拒绝未知函数、错误参数数目/类型、SORT超30项或可变模式/名次、REFX1可变N、重复/前向变量、负窗口及分析段未来绘图。256KiB源码、2048变量和16输出是项目自定审查预算，**不是官方限制**。完整主图已由现行官方解析器离线预解析，但目标版本客户端的保存、运行容量、渲染和速度仍待核验。

旧诊断摘录保留于diagnostics。JSON为参考数据，未执行其中任何代码、指令或交易示例。
