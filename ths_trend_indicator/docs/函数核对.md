# 函数与语法核对

目标是同花顺期货通电脑版的自编技术指标主图公式。以下为本包采用的**本地兼容检查配置**，不是从原生编译器导出的规范。语法校验通过表示符合此配置，不能据此宣称期货通某个具体版本已编译通过。

## 1.0.3：目标客户端4.39.1.2的保守输出

用户确认版本为4.39.1.2，且1.0.2仍在同一组合式IF赋值处被拒绝。这否定了“仅改写负数就能解决该行”的推断；不再把一元负号认定为唯一原因。

新输出采用更小的语法子集：布尔值存成0/1；AND通过两个数值标志相乘，OR通过MAX组合；需要作为函数条件的组合先命名，再使用`标志>0`。原TTSTYPE改成两个简单比较标志和`2*TTSHS*MAX(标志1,标志2)-1`，不再由含逻辑组合的IF直接返回正负号。其他组合条件同样处理。

IF的负数常量分支使用已命名数值或数值选择式；一元正负号仍不输出。标准K重复样本的中间名缩短，压缩源码体积。当前主图478个变量、16个输出；两种编码文件均在本包64KiB预算以内。这些是保守工程预算，不是声称官方限制恰好如此。

检查器会拒绝生成文件中的AND/OR表达式与IF负数常量分支。保留REF等历史语义，并将1.0.2的分析段作为独立数学对照，核对所有原分析变量。**这些本地约束不是从4.39.1.2官方编译器提取的语法规范，该客户端尚未复编译新版。**

## 1.0.2：第166行IF与负数表达式（未解决客户端报错）

用户1.0.1截图在第166行`TTSTYPE:=IF(...,1,-1);`报IF语法错误。该行还包含条件中嵌套IF；新版本将它化简为`TTSHS<>0 AND (TTSLS=0 OR TTSHT<TTSLT)`，分支改写成`1,(0-1)`。另一工作尺度的同类条件同步化简。

为避免在后续分支继续遇到一元负号解析差异，生成器全局改用带括号的0减表达式，正号直接去除，不对文本标签做查找替换。`-(A+B)`保留为`(0-(A+B))`，不能误写成`0-A+B`。检查器拒绝生成文件中的一元正负号，同时计算静态窗口常量，仍能拒绝`REF(C,(0-1))`，避免把负历史引用伪装成合法减法。

截图能确认旧行被客户端拒绝，不能单凭它断言唯一根因或所有版本的负号规则。该修改随后被用户反馈仍失败，因此只保留其中的等价改写和回归，不将它作为已解决客户端问题的证据。

## 1.0.1：交易保留名与类型

用户1.0版本截图底部明确显示 `COND_TRADE:SK参数不符合函数条件`。该错误表明客户端把`SK`按期货交易函数解析；它不能安全用作标准K变量名。1.0检查器仅列出部分行情函数保留名，漏检了交易指令，这是本次已知缺陷。

新版把标准K改名为`TTSTD`，其余内部ASCII变量统一加`TT`前缀，顶部用户设置保持原名。检查器新增`BK/SK/BP/SP/BPK/SPK/CLOSEOUT`等交易保留字，测试明确要求拒绝旧`SK:=...`写法。此列表不是客户端全部保留字清单，因此命名规则同时避开直接使用短交易名称。

同时对条件与数值做显式转换：比较结果参与标准K/目标排序时先用`IF(条件,1,0)`；数值标志作为`IF/COUNT/BARSLAST`或绘图条件时比较`<>0`；累计事件的`SUM`输入使用数值标志。检查器对算术、函数每个参数、赋值及输出推断类型，拒绝未经转换的条件加法、条件作为数值参数、裸数值作为条件参数。这是本包采用的保守子集，不能据此断言客户端不支持任何隐式转换。

这些改动已做全分析变量的数值等价检查，保留原有排序、端点与价位计算规则。**截图只验证了旧版失败的位置，新版尚未在同一客户端复编译。**

## 采用的函数签名

| 函数/变量 | 本包写法 | 约束与核对重点 |
|---|---|---|
| ABS | `ABS(X)` | 1参数 |
| MAX、MIN | `MAX(A,B)`、`MIN(A,B)` | 各2参数，不依赖多参数变体 |
| IF | `IF(条件,A,B)` | 3参数；所有分支中的除法、历史引用亦有边界保护 |
| REF | `REF(X,N)` | 2参数；N为非负整数，动态N限制在0至BARPOS-1 |
| HHV、LLV | `HHV(X,N)`、`LLV(X,N)` | 2参数；动态窗口至少1根 |
| SUM、COUNT | `SUM(X,N)`、`COUNT(条件,N)` | 2参数；只有SUM使用N=0累计历史；COUNT窗口至少1 |
| BARSLAST | `BARSLAST(条件)` | 1参数；通过累计事件数判定是否曾发生，不靠“未发生”返回值证明事件存在 |
| FILTER | `FILTER(条件,N)` | 2参数，仅用于绘图转折去重 |
| BACKSET | `BACKSET(条件,N)` | 2参数，事后回填绘图；禁止用于上游分析 |
| REFX1 | `REFX1(X,100000)` | 2参数，沿用期货通公开示例的末值冻结写法，仅用于当前图形 |
| DRAWLINE | `DRAWLINE(条件1,价1,条件2,价2,0)` | 5参数，本包不用额外颜色参数；颜色写在调用后 |
| DRAWTEXT | `DRAWTEXT(条件,价,'文字')` | 3参数，字符串字面量；不用未经核对的字符串拼接函数 |
| DRAWNUMBER1 | `DRAWNUMBER1(条件,价,数值,精度)` | **4参数**；价格2位、Q根数0位、回调1位，不混用其他平台DRAWNUMBER签名 |
| MA | `MA(C,5)` | 2参数，仅兼容检查文件使用 |
| BARPOS | `BC:=BARPOS;` | 按1起始的K线位置使用，无括号 |
| ISLASTBAR | `ISLASTBAR` | 仅绘图使用，不拿它切割上游分析 |
| DRAWNULL | `IF(条件,值,DRAWNULL)` | 不显示的价位返回空绘图值，避免0价拉坏主图比例 |

没有使用 `DRAWNUMBER`、`CON2STR`、`DRAWTEXT_FIX`、`DRAWSL`、`CONST`、DLL或其他平台特有交易指令。第三方示例虽使用DRAWSL，本包改用末值冻结后的短水平输出，减少斜率/延伸方向参数差异。

## 检查项目

- 大小写不敏感的重复定义、定义前引用、已知行情和期货交易保留字冲突；内部变量统一TT前缀。
- 分号、括号、字符串、注释、冒号与赋值的区别。
- 函数白名单、参数个数、条件/数值/文本类型、颜色与线宽、整数窗口。
- 无一元正负号；负数参数按0减表达式输出，负的常量历史窗口仍拒绝。
- 正负方向、动态历史引用钳制、除零保护和样本不足状态。
- 原始价格计算后再标注，不先四舍五入锚点。
- 绘图未来函数独立分段，分析前缀不消费回标结果。
- UTF-8 BOM与GB18030、Windows CRLF两种文件解码后全文一致。

本地配置覆盖本包使用的语法子集，不验证客户端变量数量/输出数量限制、实际速度、字体、图层遮挡、动态窗口的版本支持、末值越界时的具体行为。最终仍以用户客户端的测试/编译与显示为准。公式控制在64KiB源文字以内和16个输出以内，这是本包的保守预算，并非声称官方上限为该数值。
