# 函数与绘图语义核对

目标：同花顺期货通电脑版4.39.1.2。最新依据是用户从该客户端函数库复制的说明摘录，保存在 [client_function_reference.txt](../diagnostics/client_function_reference.txt)。不是从股票版同名函数推断。

## 确认的关键差异

| 函数 | 客户端用法 | 实际语义 |
|---|---|---|
| DRAWLINE | DRAWLINE(C1,P1,C2,P2,COLOR) | C1和C2必须在同一根K线同时满足；在该K线上从P1画到P2。不能连接不同K线的极值 |
| POLYLINE | POLYLINE(COND,DATA,COLOR) | 连接满足条件各根K线上的DATA，形成连续折线 |

两函数都不能用A:或A:=定义为变量，支持调用后的LINETHICK1至9、POINTDOT、DOT。第三/第五参数是颜色常量。

1.0.5把DRAWLINE当成了跨K线连接函数，导致文字和转折价可见，波浪线、回调线、目标线消失。之前的参数白名单和数学回归未覆盖函数绘图语义，这是实际漏检。随后给用户的小样又错误传了0，客户端明确提示“0颜色字符串错误”；该错误不能证明正确颜色参数的调用失败。

1.0.6主图17处跨K线绘图全部使用独立的POLYLINE三参数调用：历史转折用连续选点；进行中腿用最近转折与末根两点；回调、目标和参考线分别选择当前线段的两个端点，避免不同价位间互相连线。DRAWLINE只保留在兼容检查中作同根竖线示例，两条件相同。

## COUNT及数值选择

用户此前确认四行COUNT小样编译并显示：COUNT(条件,1)结果可参与MAX、加减和变量引用。1.0.6继续用COUNT作数值标志，AND用0/1乘积，OR用MAX，有限数值选择用m*A+(1-m)*B。所有交付公式没有IF/IFELSE调用或NULL/DRAWNULL，不将0乘空值当作有效选择。

REF距离限制到0至BARPOS-1，负的常量REF在转换前拒绝。生成器中的IF只描述数学模型，不能直接粘贴安装。解析器可解析公开示例中的IF/IFELSE，不声称它们在所有场景非法。

## 其他已交叉核对形态

| 函数 | 本包形态 | 使用范围 |
|---|---|---|
| ABS/MAX/MIN | ABS(X)、MAX(A,B)、MIN(A,B) | 1/2/2参数 |
| COUNT | COUNT(条件,N) | N=1为数值标志；较大窗口用于区间首次收破 |
| REF | REF(X,N) | 2参数，动态距离有边界 |
| HHV/LLV | HHV(X,N)、LLV(X,N) | 2参数，动态窗口至少1 |
| SUM | SUM(X,N) | 数值输入，N=0累计历史 |
| BARSLAST | BARSLAST(条件) | 用累计事件数另行检查是否发生 |
| FILTER/BACKSET | FILTER(条件,N)、BACKSET(条件,N) | 仅绘图回标 |
| REFX1 | REFX1(X,100000) | 按期货通公开示例冻结末值，仅绘图 |
| DRAWTEXT | DRAWTEXT(条件,价,'文字') | 3参数，颜色后缀 |
| DRAWNUMBER1 | DRAWNUMBER1(条件,价,数值,精度) | 4参数，颜色后缀；价格2位、Q根数0位 |
| MA | MA(C,5) | 仅兼容检查使用 |
| BARPOS/ISLASTBAR | 不带括号 | 位置/末根标志；ISLASTBAR仅绘图使用 |

公开示例的DRAWNUMBER是五参数、末项颜色，主图使用四参数DRAWNUMBER1。主图不使用CON2STR、DRAWTEXT_FIX、DRAWSL、CONST、DLL或交易指令。
