# 与原书及原Python指标的对应范围

本公式明确采用**双尺度转折观察**，不把右侧2/7根确认的局部高低点等同于书中Q分级的父子孙结构。自动解释是候选，人工方向和锚点用于纠正观察尺度。

原书允许多种合理数法；这也不能成为任意把五个局部点包装为完整五子浪的理由。本版主动省去未经证明的浪号，而不是用密集1–5标注制造“完整移植”的印象。

abc候选限定b不越过本次三腿起点，避免把普通顺势抬高/降低的高低点序列套成调整；这是本版选取的保守几何子集。b越起点等复杂情况保留未识别，不能据此否定原书允许的其他调整，也不是把“浪2不能越浪1起点”写成普遍数浪法则。A?只依附这些可观察的调整候选，不给每个普通局部高低点都标A。

转折严格等待右侧PN/BN根，随后回标绘图。标准K、方向、Q和位置计算只引用当前及过去OHLC；但这不代表当前尚未收盘的K已固定。历史绘图重绘、实时末根变化与上游前缀计算的因果一致性是三个不同概念。

如需要原Python指标的完整父子孙结构、书中全部调整识别与明细追溯，仍应使用原独立软件；本公式当前不具备那些能力。此范围说明随源码一起交付，不能删掉后再称“书本完整版”。
