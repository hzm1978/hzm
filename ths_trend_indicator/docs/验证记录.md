# 1.1.2验证记录

已复现两项独立问题：完整1.1.1的动态文字/数字偏移用法存在原生错误；保存内容服务接受80000字符、拒绝80001字符，超长也显示成“包含敏感词汇”。PN两行单独通过的用户反馈保留于diagnostics，不能再将首行提示归因于PN变量。

安装改为四个不超过78000字节的主图叠加层。生成器按依赖图复制必要计算，每项绘图恰好分配一次；保留全部参数、详细模式和基础观察模式。四层采用条件/数值分型，嵌套IF/IFELSE先存中间变量。动态标签直接在目标K线上绘制，并冻结其全部输入。

官方现行5.4.0.5解析器的离线语法/绘图描述见[官方解析检查.json](官方解析检查.json)，来源和旧版失败记录见diagnostics。**这些不是目标4.39.1.2界面、行情渲染或速度的实测。** 内容校验与离线解析分别记录，详见[官方解析检查说明](官方解析检查说明.md)。

本地完整检查的数量、环境、时间及文件实际SHA以[本地检查结果.json](本地检查结果.json)为准，覆盖：

- 所有交付文件的编码、无BOM/注释/隐形字符、签名/类型、历史窗口和分析/绘图边界。
- 四个安装文件的长度、绘图根节点无遗漏/重复；六组场景逐变量、线段、文字/数值与完整模型对照，包含SHOWBOOK=0、DETAIL=1和STRONG等设置。
- 最新门限与历史目标根门限不同、年龄/价格/数值随历史变化的独立小样；NaN/INT_MIN等无效偏移不能记为通过。
- 标准K独立全排序、相等/0/负价、当前根排除、长影十字。
- 独立扫描首次Q收盘/影线事件与首次相等极值时钟，四类七浪耦合、连续同级/高度合并、第五未破第三、回调超过100%。
- 长下降内部五子浪（Q=35/35）、上涨七浪、子浪时间归属；三角e高于a、A确认前失效/确认后失守及镜像。
- 前完整波段七条分割与目标互斥；同组H1最近三个未触及目标、比例和数字在线上；目标全部触及时保留状态。
- DRAWLINE同根、DRAWLINE3后续配对与位移；反转几何、标准大小和关键位置分别核对；分析段前缀因果性。

标注位置回归.json另记录1.1.1数学模型与新标注方法六场景逐项等价；预览见[previews](previews/)。这些K线是明确的合成OHLC，不是用户品种行情或原生截图。有限层级、复杂调整覆盖和量化约定仍见[实现范围](实现范围.md)。
