# 1.1.3验证记录

本版针对“EWT02慢且不正确、四层加载后自编公式消失”的反馈，改为两层推荐、一层可选。子浪线、Q、回调数字和标签归在同一层，前两层不再缺少另一层才有的子浪线。消失的现场原因未复现，未将其归因为运行慢或超时删除。

## 实际原生计算

使用官方5.4.0.5安装包内的计算DLL，仅在合成OHLC上离线运算；不启动客户端、不登录、不请求外部行情、不执行交易或通知回调。目标4.39.1.2界面未运行。版本、DLL/检查脚本/数据/源码SHA保存在原始JSON中。

- `原生计算样本.json`保存18项原生计算：六个场景乘三个安装文件，包括人工下降H1目标。
- `原生计算核对.json`逐项比较实际线段起止坐标、标签的K线位置、价格、文字及对齐，价格坐标比较保留7位小数。不是只检查ErrCode。
- `官方解析检查.json`另外检查三个安装文件的原生语法与绘图描述，正反小样验证错误码与NaN/INT_MIN偏移防线。
- `原生计算耗时.json`保存旧EWT02的331根基线和新版两层1000根的计算时间。新版331根的计时在原生计算样本中。新EWT02功能比旧任意拆分层完整，不能把差值视为同一代码的单因素性能试验；没有测量客户端界面速度。

已实际复现并处理：

1. 原生`FILTER(BACKSET(...),N)`与先保存BACKSET序列再FILTER的结果不同。安装导出先物化BACKSET，六场景核对排除多余转折。
2. 文字与数字用同一原生对齐枚举：0左、1中、2右，9号字体。修正旧审查器的KTEXT左右反向解释。
3. `DIR:=(0-1);`能预解析，但原生计算DIR为空；`DIR:=0-1;`计算为-1。负参数赋值去掉整个右侧的冗余括号，比较和函数参数中仍保留所需括号。原始对照见`../diagnostics/原生负向赋值对照.json`。
4. 快照扫描保留在`IF(ISLASTBAR,扫描,0)`内部，然后广播给历史绘图；没有将扫描提到无条件历史变量。避免每根反复扫描相同末端区间。

## 本地回归与内容校验

本地完整检查及专项补充的实际数量、时间、结果以`本地检查结果.json`及`专项检查结果.json`为准。覆盖公式语法/类型/函数签名、独立标准K排序、Q事件计数、四类七浪耦合与合并、回调、A确认/失效、价格尺互斥、反转几何、分析段因果性、分层逐变量与逐坐标等价。新增回标先物化、原生保留变量避让、最后一根扫描保护与负向赋值的回归。

安装固定书本简洁显示：SHOWBOOK=1、DETAIL=0，删除这两项运行分支；完整开发模型仍可检查其余模式。其他参数可编辑，STRONG/SHOWK覆盖及不带孙浪的推荐两层单独比较。各文件小于79000 ASCII字节，图形根无重复或遗漏。

`官方内容校验结果.json`记录最终公开源码匿名下载核对后的官方350/550内容校验，与本地或原生计算分开。80000通过、80001拒绝是2026-11-05服务实测边界，非永久编译器限制；不再推测PN或中文是敏感词。

六组合成预览与结构明细见`previews`。历史`标注位置回归.json`记录1.1.1与1.1.2的对照，不作为1.1.3原生计算证据。调整形态、层级深度和量化约定仍见`实现范围.md`。计算通过不等于对真实市场结构解释的唯一认定。
