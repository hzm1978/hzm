# 验证记录

本记录的“通过”仅指交付源码的本地检查。**没有在期货通电脑版原生编译或实际加载主图；不能宣称客户端无语法错误或全部函数兼容。**

实际运行环境与每个公式文件的SHA-256、字节数、语句数、输出数、使用函数及回标位置，见[本地检查结果.json](本地检查结果.json)。可运行 `python verify.py` 重新生成报告。

## 已完成

- 主图与兼容检查公式的UTF-8、GB18030共4份文件通过本地解析；两种编码解码后全文一致。
- 34项本地自动测试通过，无跳过。覆盖书本小/大Q比较边界、标准K独立排序、40个排名唯一、当前K不参与门槛、历史不足、平盘和零价、上下方向对称、回调超过100%、完整前腿人工锚点、错误历史范围、价位尺互斥、正确目标起算点与最近三档筛选、人工0价锚点、关键反转位置及大小门槛、避免把正常同向高低点序列套作abc调整。
- 在同一OHLC前缀上分别运行短历史和更长历史，逐一比较分析段全部变量，数值一致。该测试不包含绘图回标，不证明历史绘图不会重绘。
- 独立排序预期核对标准K，而非用同一段公式再计算一遍预期。
- 独立检查Q事件发生前是否已经收盘越过起点极值，核对时钟排除起点、实际转折年龄和交替方向。
- 下降后反弹的手工价位例子：3919.71→3174.45，50%=3547.08，61.8%=3635.02，78.6%=3760.22；按原始端点计算后保留2位。
- 检查器能拒绝未审核函数、`DRAWNUMBER1`错误参数数目、`DRAWLINE`错误参数数目、重复/前向引用/已知保留名、缺分号、未闭合注释、负历史引用及分析段混入未来函数。
- 源码生成器、检查器和回归文件可用Python字节码编译检查；复查不需要TqSDK、账号或交易连接。
