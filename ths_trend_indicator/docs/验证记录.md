# 验证记录

## 现场事实

1.0.4曾被用户反馈编译失败；COUNT四行独立小样已由用户确认编译显示。1.0.5实际截图证明数值和文字可显示，但波浪和价位线缺失，方向/回调及文字密度不符合要求。

用户提供4.39.1.2函数库说明，确认DRAWLINE只画同一根K线，POLYLINE才跨K线连接。这是此次绘图根因的直接依据，记录见diagnostics。1.0.6已据此改写；**完整1.0.6尚未在该Windows客户端编译和加载**。

## 本地检查

实际时间、环境、70项测试结果、文件SHA-256、函数/变量/输出/字节数见 [本地检查结果.json](本地检查结果.json)。`python verify.py`不会启动同花顺官方编译器。

- 主图与两种兼容检查共6个公式文件完成解析、参数与类型检查；UTF-8 BOM和GB18030的CRLF内容一致。主图无DRAWLINE，无IF/IFELSE、NULL/DRAWNULL。
- 按客户端DRAWLINE语义重现旧故障：分别在第2、第5根成立的两个条件不会画跨K线段；同根成立只画竖线。
- 执行实际导出绘图AST，在合成长期下降后反弹例子上验证：工作方向为-1、末段调整；回调尺保留4801→2199的整个工作段，绘出7条有实际跨度的水平线且不画目标，历史波浪有跨K线线段。
- 顺势人工H1例子验证只有最近3个未触及目标，没有回调尺；每条线上比例和价格都位于线段内部并离开最右边界，避免只见比例而价格挤出屏幕。
- 默认标注数低于详细模式一半，不再在每个细Q重复“细Q收破”文字。预览不另行隐藏标签来伪造这一结果。
- 跌破先前已知工作低点后，即使旧高低点上升条件仍成立，下一根也不会恢复旧上升方向。
- 横盘且工作方向待定时使用最后完整工作腿的黄金分割，不强求趋势方向或给出顺势目标。
- 趋势参考回推到实际同侧锚点；平移参考独立使用对边斜率。尚未证明完整包络或正式A点。
- 标准K由独立排序预期验证：前40根实体前5、同体近者优先、当前根排除；不足40根不缩短窗口。Q首次收破、实际时钟/转折年龄与级别边界保留回归。
- 旧版冻结数学参考仍用于未改变的标准K、转折及Q测量。方向、自动回调锚点、平移参考和调整阶段门槛已按此次缺陷修订，不再声称所有旧值应当相同。
- 数学模板与导出逐分析变量一致；分析前缀因果性、短历史、0/负价、除零保护、REF非负整数且不超历史均通过。绘图回标不属于前缀不重绘保证。
- 检查器拒绝未知函数、参数/类型错误、重复/前向引用/已知交易保留名、缺分号、负窗口及分析段混入绘图未来函数。
