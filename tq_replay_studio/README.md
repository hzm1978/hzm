# 天勤复盘工作台 1.0.1

[下载完整源码ZIP](https://github.com/hzm1978/hzm/raw/refs/heads/feat/tq-replay-studio/tq_replay_studio_v1_0_1_source.zip)

一套独立的 Python／PySide6 桌面软件，以 **天勤 TqSdk API** 为行情、合约目录、历史回放和实时交易接口。完整源码、测试、安装脚本及规则说明都在本目录；可以单独解压运行，不依赖旧复盘程序或旧行情目录。

支持三个相互独立的工作场景：

| 场景 | 数据与账户 | 用途 |
|---|---|---|
| 历史复盘训练 | 天勤历史／缓存／导入文件，冻结训练快照，本机模拟账户 | 播放、画线、策略判断、模拟开平仓及止盈止损 |
| 实时模拟买卖 | 真实实时行情，官方 TqSim 或 TqKq | 在实际合约上模拟下单、撤单，查看资金、持仓及成交 |
| 徽商期货实盘 | 官方 TqAccount，柜台 H徽商期货 | 登录真实账户，核对后提交限价开平仓、平今及撤单 |

**实盘连接代码已实现，但没有使用用户真实资金账号联机或发送真实委托。** 实盘界面默认锁定，需要本机输入资金账号和交易密码、明确解锁、逐单确认；详情见 [交易接入说明](docs/交易接入说明.md)。

本次修复：[PySide6缺失及Python版本不兼容](docs/启动修复说明.md)。

## 安装与启动

推荐 Windows 10／11。程序环境使用64位 Python 3.11—3.13，启动器可从已有较新或较旧Python中运行并自动准备兼容环境。第一次使用：

1. 完整解压源码文件夹。
2. 直接运行 **启动工作台.bat**；首次自动检查并安装依赖。
3. 也可先运行 **安装依赖.bat**，成功后再启动。
4. 点击 **连接天勤** 填天勤／快期账号。可先点 **演示行情**，无需账号体验界面。

命令行：

~~~bash
python -m pip install -r requirements.txt
python run.py
python run.py --demo
~~~

若原来的.venv版本不兼容，启动器保留原目录，创建.venv-studio专用环境。没有兼容Python时从Python官方NuGet下载固定版本3.13.17（约15MB），核对SHA-256后使用，不修改系统Python。安装日志为setup.log；默认包源失败会改用清华HTTPS镜像重试。Qt仅安装本程序需要的PySide6-Essentials，减少下载。

源码不是独立exe；可用 **构建Windows.bat** 在Windows本机构建。该构建保留控制台以支持后台进程标准输入输出；云端没有执行Windows安装器、DPAPI系统调用或exe构建。

| 保存和恢复 | 自动保存训练位置、冻结行情、持仓、委托和各图画线；训练记录可恢复，整个工作区可导出并在独立窗口打开 |

逐根推进以真实基础K线为单位，不插造分钟内价格。需要更细复盘时选1分钟；副图不生成小于基础周期的假K线。副图标明“合成”，盘中大周期按时间边界聚合，其边界可能与交易所原生周期不同；要研究某个原生周期，可直接把主图切到该周期。

图表、书本指标的数学模块由此前已验证代码独立内置在 technical 包内；新窗口、数据进程、SQLite、复盘、训练账户及交易接入是新的实现。没有把旧程序改个名称作为新软件。

## 数据范围：2016与10000根

这两件事需要分开：

- **实时订阅**：get_kline_serial 每周期请求最近最多10000根；日线可覆盖多年，分钟不能由此保证从2016年完整取到现在。已有更老缓存不删除。
- **历史回放**：TqBacktest 根据指定交易日逐步返回历史，不是实时最近10000根模式。本次普通账号实际取得沪银2016-01-05—2016-01-06共1110根分钟K线。
- **专业版历史批量下载**：本软件没有调用 DataDownloader 或仅限专业版的指定日期序列下载方法。

不是所有品种都从2016年上市；最早日期、交易时段、权限和数据空缺以接口实际返回为准。历史载入窗口显示接收根数及实际起止时间；夜盘可能在前一自然日晚上，按所选交易日归属收录。

历史分钟建议分月／季度载入。SQLite保留所有接收资料，单次训练／缓存预览最多装入100000根基础K线；更长历史可按日期分段选择。实时看盘最多显示10000根，指标默认分析最近1600根已收盘K线。

## 开始一场训练

选品种和周期 → 点击 **新建复盘** → 选择起点、资金、乘数、保证金、手续费和滑点 → 开始推进并模拟交易。

每场训练冻结自己的数据及参数；后台行情继续保存而不改写训练快照。高周期图只看已揭示基础K线。已有委托／成交的训练禁止回退，可新建一场从较早位置重来；向前跳转会顺序处理途中每根K线，限价和止盈止损不会被跳过。

历史市价训练采用已知收盘价加滑点，限价从下一根开始撮合；同根同时触及止盈止损时先计止损。它是K线级训练模型，不模拟逐日结算、强平、盘口排队或交易所全部费用规则。实时交易另使用SDK账户回报。

## 实时模拟与徽商账户

点 **实时模拟／实盘**，选择：

- **TqSim**：真实行情、本机模拟账户；结束该SDK会话后重新开始。
- **TqKq**：快期云端模拟账户，记录按快期服务保存。
- **徽商实盘**：在本机输入期货资金账号和交易密码，默认柜台 H徽商期货。天勤账号用于服务认证，资金账号用于券商账户登录，两者不同。

交易窗口把主连解析为实际合约；显示资金、今昨持仓、委托、成交及柜台信息。支持对手价限价／指定限价、开平仓、上期所及能源中心平今、撤销选中委托及成交导出。

实盘每次连接默认锁定；解锁后仍需逐单确认。默认单笔最多5手、名义金额500万元、报价时效120秒，可在连接前调整。确认20秒过期，凭确认令牌只发送一次，异常不自动重试；具体成交以柜台返回为准。隐藏窗口会重新锁定实盘，关闭软件不会自动撤销柜台委托。

历史复盘的止盈止损仅作用于该训练账户；实时交易窗口提供手动限价开平仓，不会自动把历史训练条件转为真实订单。具体席位／穿透认证等要求以徽商和天勤返回为准。

## 文件与隐私

行情、训练及显示设置保存在当前用户数据目录 TqReplayStudio/studio.sqlite3，可通过 --database 指定其他工作区。Windows天勤账号可用当前用户DPAPI加密记住；真实资金账号和交易密码只在本次交易窗口内使用，不保存到工作区或源码。工作区备份不包含登录文件。

源码包不包含真实密码、用户行情库、PDF、虚拟环境或数据库。
