# 实时模拟与徽商期货实盘

## 账户选择

历史训练账户只看冻结的历史K线，在主窗口右侧操作。菜单“行情 → 实时模拟／徽商实盘交易”打开另一个交易窗口，其交易由官方SDK账户处理，跟主窗口训练记录独立。

| 账户 | 代码 | 记录保存 |
|---|---|---|
| 本机实时模拟 | TqSim | 该SDK会话内；断开重连开始新的模拟账户 |
| 快期云端模拟 | TqKq | 快期服务器按其账户规则保存 |
| 徽商真实账户 | TqAccount("H徽商期货", 资金账号, 交易密码) | 由真实期货柜台管理 |

官方名单在本次核对时将徽商列为免费版可用公司，完整柜台字符串为H徽商期货。具体CTP席位、穿透认证、账户绑定等要求仍以柜台实际回复为准。官方说明普通快期账户默认最多绑定三个实盘账户；首次使用可自动绑定。

## 本机登录步骤

1. 主窗口先连接天勤／快期账号。
2. 打开“实时模拟／实盘”，先选希望使用的账户类型。
3. 若选徽商实盘，在本机填写期货资金账号和**交易密码**。这些不是天勤账号或资金转账密码。
4. 在连接前设置单笔手数、名义金额和报价时效上限，再连接交易账户。
5. 界面显示账户资金、实际合约、报价、今昨持仓、委托和成交。账户连接后参数固定，变更参数需要断开再连接。

本软件不保存资金账号／交易密码到数据库或源码。不要把这些信息提交到GitHub；在本机界面输入即可。

## 实盘下单

真实账户登录后下单默认锁定。勾选“启用实盘下单”，输入“启用实盘”解锁本次连接。每笔委托另弹出核对窗口，明确显示公司、资金账号尾号、实际合约、方向、开平、手数、限价、名义金额和报价时间；取消则不发送。

默认5手、500万元名义金额、120秒报价时效。只支持限价：可选择实时对手价作为限价，或手工指定。价格需符合最小变动价位、涨跌停及交易所单笔手数要求。只接受未到期实际期货合约；主连会解析实际标的，不能直接把KQ.m@发送给柜台。

上期所／能源中心普通平仓按昨仓核对，平今按今仓核对；其他交易所使用普通平仓。程序检查持仓与冻结数量，最终可成交数量、保证金和结果由柜台决定。

确认生成20秒有效的一次性令牌。发送前再次检查合约、报价时效、锁定状态和参数；重复、过期或品种已切换的确认会拒绝。令牌在调用SDK前消费，发送异常不自动重试，以避免状态不明时重复报单。

## 撤单与退出

在委托表选中订单后点“撤销选中委托”。即使实盘下单已锁定，仍可撤销当前账户中尚有效的委托。真实撤单也需确认；实际结果查看柜台回报。

隐藏／关闭交易窗口会锁定实盘。关闭整个程序或断开连接**不会自动撤销柜台委托**；仍有未成交真实委托时，界面会提示。主窗口中的训练止盈止损和回测策略不会自动变成实盘条件单。

## 测试边界

实盘解锁、逐单核对、一次性令牌、异常不重发、平今／平昨、撤单及凭据脱敏通过模拟网关和真实Qt检查。没有用户真实资金账号，所以没有进行徽商实盘联机、真实委托或真实撤单。

真实SDK的TqSim开仓／平今已在官方TqBacktest历史交易时钟下完成。收市时直接测试实时模拟未成交，未算作成功成交；SDK模拟也检查可交易时段。TqKq云端模拟没有额外实际联机验证。
